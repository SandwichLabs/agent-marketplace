# Tagging clients FAQ

Tagging lets the software remember the clients shown on one screen (a report, class roster, directory) so they can be reused: filter other reports to just those clients, build mailing lists, bulk-modify them, or register them all into a class or course.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_clt_lkup.asp (Client Directory)
- Menu path: **Clients** (left nav); tag icons also appear on most **Reports**, the Class Sign In screen (top right), course rosters, and each Client Info screen (icons beside the name).

## Steps
### Tag clients from a report
1. Open a report; if the three tag icons are present, it supports tagging.
2. Run it with the filters you want.
3. Click an icon: **Tag add** (adds the results to your existing tag list), **Tag new** (discards the old list and starts a new one from these results), or **Untag clients** (removes the results from the list).
4. On other reports, tick **Tagged Clients Only** / **Show tagged clients only** to limit results to the tagged list.

### Tag in classes and courses
1. On the Class Sign In screen or a course day roster, use **Tag add** or **Tag new** for the people listed.
2. To enrol a tagged list elsewhere, open the target class or course and click **Register Tagged Clients**.

### Untag a subset (example: active clients minus suspended)
1. In the Client Directory, list active clients and click **Tag add**.
2. Tick **Suspended Clients**, generate that list, then click **Untag clients**.
3. Run Mailing Lists on the tagged result.

### Clear the whole tag list
1. In the Client Directory, under Filters click **Clear** next to "Tagged clients only".
2. Click **OK** on the confirmation.

## Gotchas
- Staff need the **Tag clients** permission (Reports section of staff permissions).
- Tag lists are stored per login; another staff login does not see yours.
- Large data sets or a slow connection can hit a 30-second timeout, making the tag buttons look dead.
- Untagging only removes people from the list; it does not deactivate or delete clients.
- Tag new wipes the previous list (not the clients).
- Tagged lists can feed the Mailing Lists report and the Modify Tagged Clients tool (indexes, client types, contact logs, measurements, sales reps).
