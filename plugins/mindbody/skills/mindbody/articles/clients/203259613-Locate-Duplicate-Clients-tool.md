# Locate Duplicate Clients tool

Finds client profiles that probably belong to the same person (different email, formal vs nickname such as David and Dave) so they can be merged.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_dupclients.asp
- Menu path: Settings > Clients > **Locate Duplicate Clients** (or search for it in the Settings search bar).

## Steps
1. Open Locate Duplicate Clients.
2. Enter **Number of characters to match** for the first name.
3. Enter the number of characters to match for the last name.
4. Click **generate**.
5. For a likely pair, click **Merge These Clients**, which opens the Merge Duplicate Clients tool.

## Settings & fields
- Character counts set how many leading letters must be identical. With 2 on first name, David, Danny, Darren and Daryl all match ("da"); with 3 only Darren and Daryl match ("dar").
- Last name is usually the better field to match on, since duplicates more often share a surname than a first name.

## Gotchas
- Staff need the Locate duplicate client records permission.
- Inactive profiles are included in results.
- Availability depends on the software package.
- Duplicates are also flagged when adding a client in the Mindbody Business app, but merging itself can only be done in the full software.
- Duplicates cause trouble when a client's pricing options or visits sit on one profile and they sign in to the other.
- ⚠️ Irreversible / financial — confirm with the user first: the merge step that follows cannot be fully undone.
