# How to search for clients using the Client Directory (Advanced Client Search)

Explains quick client search in the toolbar and the full Client Directory with its search fields, filters and saved searches. Use it to find a client or build a filtered client list.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_clt_lkup.asp
- Menu path: **Clients** in the left navigation; quick search is the **Find a client** field at the top.

## Steps
### Quick search
1. Click **Find a client** and type a name; previously searched clients autofill while you are logged in.

### Client Directory
1. Click **Clients**.
2. Choose a field in the "Search client by" dropdown (default All fields).
3. Optionally open **Filters** and set criteria.
4. Enter a term and click **Search**. Staff with Ability to view all clients can click into the box and press Enter for the full list.

### Save a search
1. Set filters in **Filters**.
2. Click the **Save this report** icon, name it, click **Save Report**.
3. Reopen via the **Saved** menu; hover and click **X** to delete one. Running a saved search with changed filters does not alter the saved version; saved results refresh automatically.

## Settings & fields
- Search by: Last name, First name, Middle name, Nickname, Gender, Email address, Phone # (no symbols/spaces), City, State/Province, Country, Postal code, ID.
- Client Info filters: Relationship, Location (multi-location), All clients (active/inactive/all), Gender, Membership, Clients w/ an alert (yellow), Clients w/ a staff alert (red), Suspended clients (needs Scheduling Suspensions), Clients w/ a current contract (based on contract dates, so a terminated contract with a future end date still matches), Clients without a referral, Tagged clients only, Third-party payer, Client type, Belt levels (needs belt tracking), Age (needs Children's program feature).
- Sales Info filters: Contact log status, Profile creation date, Sales Reps, Sales status, Prospect stages.
- Advanced Search: First contact date, Expected close date, Actual close date (first purchase), Pregnancy due date, Client Indexes, Liability Waiver (Signed/Unsigned/Any). Custom fields can add more filters.

## Gotchas
- Needs Ability to view all clients (Sales Team Management) and View client info (Clients). Availability depends on software package.
- Full-name searches containing hyphens or spaces return nothing; search by last or first name separately.
- Inactive clients are hidden unless the status filter is changed (see deactivation article).
- Cross-regional sites may behave differently.
- Each permission group can choose which client tab opens first.
