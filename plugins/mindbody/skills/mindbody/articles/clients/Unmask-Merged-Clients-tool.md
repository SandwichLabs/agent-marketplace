# Unmask Merged Clients tool

Separates two profiles that were merged by mistake back into two working profiles. It is a partial rescue, not a true undo.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_unmask_mergedClients.asp
- Menu path: Settings > Clients > **Unmask Merged Clients** (or type the name in the Settings search bar).

## Steps
1. Open Unmask Merged Clients.
2. Find the profile to release and click **Unmask Client** beside it.
3. Confirm the "released successfully" message; click the linked name to open the restored profile, or **Back** to unmask more.
4. If the site has over 2,000 merged profiles: tick **Show more page options**, pick the page you want, click **Show Merged Clients**, then unmask.
5. Review both profiles and restore missing data by hand (below).

## Settings & fields
- Column headers sort the list by client ID, first/last name, the profile it was merged into, staff who merged, staff ID or merge date.
- The original client ID is given back to the unmasked profile.
- Manual repair after unmasking:
  - Client types and relationships: reassign.
  - Contact logs: re-enter or copy.
  - Documents: resubmit.
  - Purchase history: move each sale to the right client (see the edit purchasing client article).
  - Visit history: early cancel and rebook for the original client.
  - Formula notes: re-enter before checking out the appointment.
  - Billing information: cannot be moved; check both profiles and re-enter the card where needed.

## Gotchas
- Staff need the Merge duplicate/unmask client records permission.
- Unmasking does not reverse the merge and not everything is restored.
- Contact details, profile notes and billing info are split back to the two originals, so verify who gets billed.
- ⚠️ Irreversible / financial — confirm with the user first: wrong stored billing data after unmasking can cause the wrong client's card to be charged on autopays.
