# Client Types screen

Client types are extra labels (e.g. senior, student, veteran) you create and attach to client profiles. Once assigned they can filter reports and act as prerequisites for classes or courses.

## Where in Mindbody
- Direct links: https://clients.mindbodyonline.com/app/clients/client-types ; https://clients.mindbodyonline.com/app/business/servicesandpricing/Classes (for auto-assign)
- Menu path: **Settings > Clients > Client Types**

## Steps
### Create a client type
1. Open **Client Types**.
2. Click **Add new** (top right).
3. Type the name in **Add client type**.
4. Click the checkmark to save.
5. The type appears in the Client Type column, where you can toggle it active/inactive or delete it.

### Assign to a client
1. Open the client's **Client Info** screen and expand **Client Types**.
2. Pick one in the **Add a client type** dropdown; it saves automatically. A client can have several.
3. Remove one with the **X** on its right.

### Auto-assign via a class
1. Go to **Services & Products > Classes** and click the class name.
2. Expand **Additional Options**.
3. Click **Select** next to "Auto-assigned client types".
4. Tick the types and click **Save**.

## Settings & fields
- Columns Client Type name and Active are sortable; hold Ctrl or Shift (Command on macOS) while clicking headers to multi-sort (numbers show priority).
- Active toggle per type; delete removes it permanently.

## Gotchas
- ⚠️ Irreversible — confirm with the user first: deleting a client type is permanent; deactivate instead if unsure.
- Auto-assignment only works if that option is available in the class's Additional Options.
- The Modify Tagged Clients tool can assign types to many clients at once, but at least one type must exist.
- Client types vs client indexes: types allow several per client (survey-style); indexes give one value per index (e.g. one age range).
- Availability depends on software package.
