# Client profile information FAQ

Quick answers for common Client Info screen tasks: email subscriptions, client IDs, creation info, documents, photos, reactivation, default location. Use when a client-profile field or button is missing or behaves oddly.

## Where in Mindbody
- Menu path: Client Lookup > open a client > Client Info screen. Settings toggles are under **Settings** > **More** > **General Setup & Options** > **Client Management**.

## Steps
### Set client subscriptions
1. On Client Info, expand **Contact & Subscriptions**.
2. Tick any of: **Account management** (contract/autopay notices), **Reminders and schedule changes** (booked services), **News and promos** (marketing).
3. Click **Save**.

### Make the ID "Assign" button appear / change a client ID
1. In General Setup & Options, expand **Client Management**, tick **ID Cards**, click **Update** (re-login if it does not show).
2. Client Info > **Edit name** > next to ID click **Assign**, edit the code, click **Update**.

### Recycle an ID card for reuse
1. Open the original client, **Edit name**, **Assign** next to ID.
2. Change the code systematically (e.g. SOK1234 to XSOK1234 to flag inactive).
3. **Update**; then issue the old card to the new client using the new-barcode steps.

### Check profile creation date and origin
1. On Client Info, expand **History**.
2. A "created by" field naming a staff member/owner means it was made in the business site; no such field means it was created online/consumer site.

### Attach a file
1. General Setup & Options > **Client Management** > enable **Client Document Uploads**; log out and back in.
2. Open the client, click **Documents** (top right) > **Browse** > pick file.

### Add a client photo
1. On Client Info click **Photo** > **Browse** > **Upload**.

### Reactivate an inactive client
1. Client Lookup, expand **Filters**, switch "Active Clients" to "Inactive Clients" or "All Clients", search.
2. On Client Info click **Activate** (far right).
3. Re-add them to the class sign-in sheet if needed.

### Change default location
1. On Client Info open the **Address** field, change **Location**, **Save**.

## Gotchas
- Creation date only displays if **Sales Team Management** is enabled in General Setup & Options.
- Usernames cannot be cleared. Legacy non-email usernames persist, though the client can log in with username or email.
- Document uploads max 5MB per file.
- Photo upload works only in the business site and Mindbody Business app.
- An inactive client auto-reactivates when they log in to the consumer site.
- Some features depend on software package.
