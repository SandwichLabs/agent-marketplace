# Client forms overview

How to build paperless client forms (intake questions, policies, optional liability waiver, signature/initials) and control who gets them and when. Use when a studio wants forms sent automatically with bookings, on profile creation, or on membership purchase.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/ClientForms
- Menu path: Settings > General > Client Forms and Liability Waiver (or search it) > **Create new form**
- Completed forms per client: client profile > Documents

## Steps
1. Open the Client Forms and Liability Waiver screen, click **Create new form**.
2. Fill form information (below), personal info checkboxes, custom questions, policies.
3. Choose recipients and send timing (booking-based forms), optional expiration and reminders.
4. **Preview** to check, then **Save**. Saving with a send option selected sends it out; with none selected it stays a draft.

### Custom questions
1. **Add custom question/statement**, type the text, choose **Question type**: **Open text**, **Multiple choice** (keep to about 45; **Allow more than one answer** toggle) or **Statement** (read-and-initial, no answer).
2. **Required** is on by default; toggle **Require initials** if wanted; click **Done**.

### Manage forms
- Client Forms list columns: Name, Last updated, Waiver included, Client type (All/New), Activate/Deactivate, Copy icon (duplicates everything then opens setup), trashcan (permanent delete).

## Settings & fields
- **Name** (required; shows in notifications, at top of form, on Documents).
- **Who fills this out**: Client, or Staff only (not emailed; must be manually sent to the client's Documents screen first, then staff completes it).
- **What kind of form**: **Sent with a booking** (pick service categories/services) or **Sent without a booking** with **When should this form send**: **Profile Creation**, **Manual**, **Membership purchase**.
- **Service category** (required for booking forms; pick all for a general intake) and **Service** (blank = all in the category).
- **Description**: shown under the title to clients.
- Personal info: first name, last name, email always required; optional phone, address, preferred contact method, date of birth.
- Field mapping toggle: submitted answers can update profile open fields (phone, address, preferred contact method, DOB, prefix, nickname, home/work phone, emergency contact); name and email prefill but are not editable.
- Policies: **Add cancellation policy**, **Include liability waiver in this form**, **Add more policies**; **Require client signature** (needs at least one policy; otherwise clients tick a checkbox).
- **Require initials**: per question/statement/policy, up to 5 characters, mandatory before submit.
- **Who should get this form**: only when a new client books; first time any client books; or anyone booking (**Send once** or **Send with every booking**; multi-day courses send per day).
- **When do you want to send this form**: link after the client books (confirmation emails) or after the client confirms (reminder emails).
- **Expiration settings**: Days/Months/Years, default 12 months; booking forms only.
- **Automated reminders**: Hours/Days before the appointment or class; booking forms only.

## Gotchas
- Permissions: Manage client forms (Settings); in Clients: View/re-send forms, Print/Download client forms, Delete client forms, Fill out client forms from the profile.
- Links only generate if the notification contains the <CLIENTFORMS> replace phrase, and the Client forms notification (and service reminder notifications) is turned on (Settings > Auto Emails).
- Not shown in class or retention-marketing reminder texts. Class Check-in app bookings send no confirmation email, so no auto forms.
- Profile Creation and Membership purchase only apply going forward.
- Clients can still enroll without completing forms.
- Turning on expiration expires already-completed forms older than the period immediately; expired forms are not auto-resent, the client is prompted at next booking.
- Adding a signature requirement later needs the form resent; otherwise clients only see the checkbox.
- If a booking is cancelled, pending forms disappear; completed ones remain.
- ⚠️ Irreversible / financial — confirm with the user first: deleting a form (trashcan) cannot be undone; deactivate instead.
