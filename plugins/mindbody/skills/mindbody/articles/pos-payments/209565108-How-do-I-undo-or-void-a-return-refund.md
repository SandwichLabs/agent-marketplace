# How to undo a return

Reverses a return that was processed by mistake by voiding the return sale. Afterwards the return can be redone correctly.

## Where in Mindbody
- Menu path: client lookup > client **Purchases** screen > Manage Sales screen

## Steps
1. Look up the client and open **Purchases**.
2. Find the incorrect return sale; click its **Sale ID** (left) or **Return/Void** (right).
3. On Manage Sales click **Void** (far right).
4. Click **Yes, Void This Sale** to confirm.
5. Back on Purchases, redo the return if needed.

## Gotchas
- ⚠️ Irreversible / financial — confirm with the user first.
- Returns made to a credit card cannot be voided; once completed they are final.
- Package-dependent feature.
