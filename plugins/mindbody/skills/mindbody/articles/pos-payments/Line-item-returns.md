# How to process line-item returns

How to return one item from a multi-item sale, or part of a quantity (e.g. 1 of 2) sold on a single line. Use when a client wants a partial return of a ticket.

## Where in Mindbody
- Menu path: client profile > Purchases screen > **Sale ID** or **Return/Void** > Manage Sales screen.

## Steps
### Return a single line item
1. Look up the client and open their Purchases screen.
2. Click the **Sale ID** or **Return/Void** for the sale.
3. On Manage Sales, click **Return this item** beside the target item.
4. On Return / Issue Refund, enter a reason.
5. For products, tick **Add items back into inventory?** if stock should go back.
6. Click **Choose Refund Method**.
7. Pick a **Refund method** (original payment, Account, Cash, etc.). To split, tick "Use additional refund method?" and choose a method for each part.
8. Click **Save No Receipt** or **Save Print Receipt**.

### Partial return of a line with quantity above 1
1. Follow steps 1-4 above.
2. Untick the add-back-to-inventory box.
3. Click **Choose Refund Method** and edit the refund amount to quantity returned x unit price (e.g. 2 of 3 shakes at $7 = $14).
4. Recheck that the inventory box is still unticked, then **Save No Receipt** or **Save Print Receipt**.
5. Manually correct stock via the Inventory on Hand report.

## Gotchas
- ⚠️ Irreversible / financial — confirm with the user first. (Returns can be undone only through the separate undo-return process.)
- Card, ACH, or Direct Debit: only one line-item return is allowed per transaction; after one, the rest of the ticket cannot be returned.
- TSYS: the transaction must be fully settled first.
- Paysafe: line-item returns not allowed; use the Paysafe partial refund process.
- Inventory is not auto-adjusted for partial-quantity returns.
- Prevention tip: ring up each unit as its own line before checkout.
- Feature availability depends on software package.
