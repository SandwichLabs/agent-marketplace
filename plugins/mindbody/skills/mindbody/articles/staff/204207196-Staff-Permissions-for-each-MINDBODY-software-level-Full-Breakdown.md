# Staff permissions for each Mindbody software package - Settings

A matrix of which Settings permissions are on by default for each role under each software package. Use it to predict what a login can do out of the box, or to tell whether a missing permission is a package limit versus a group configuration.

## Where in Mindbody
- Reference only; permissions are edited at **Settings > Staff > Staff Permissions** (see [Staff Permissions - Settings](Staff-Permissions-Settings.md)).

## Reading the table (as the source lays it out)
- Nine role columns across three packages: Starter (Owner, Manager, Staff), Accelerate (Manager, Front Desk, Staff), Ultimate/Plus (Manager, Front Desk, Staff). The article does not label Starter's first column beyond "Owner"; treat that reading as likely, not certain.
- Owners in Accelerate and Ultimate have every permission on by default.
- These are defaults, not hard limits for permissions an owner can toggle.

## Highlights (defaults)
- **Staff role (all packages)**: almost nothing, apart from Complete sales transactions at POS and Pay for Another Client at POS (all packages), View Services & Pricing (Starter), and in Accelerate/Ultimate also Manage client forms, Manage data privacy requests, Virtual Wellness reports.
- **Starter Manager**: broad class, staff-info, client-cleanup, pricing-view, retail-view and sales permissions; lacks Schedule resources, Block copy/cancel, Administer staff logins, Administer permission groups, Session Type/Class Type, Void/edit past sales, Inventory, Create products at POS.
- **Accelerate/Ultimate Manager**: nearly everything on, except Media Management, Set up payment methods/room numbers, third-party payer permissions, Set up localization, Edit semester setup, ICD codes, Allow users to switch between locations, Download video on demand.
- **Front Desk (Accelerate/Ultimate)**: mainly Schedule substitute teachers, Room scheduling, Mass cancel, Locate/Merge duplicate clients, Print product barcodes, Edit sale activation dates and discount, Void/edit past sales (Ultimate only), Issue sale refunds, Issue refunds to credit card, POS and Pay for Another Client, Manage client forms, Manage data privacy requests.
- **Not enabled by default anywhere**: Media Management, Set up room numbers, third-party payer permissions, Edit semester setup, Add & manage ICD codes.
- **Only Starter Owner column**: Set up localization, Allow users to switch between locations, Download video on demand.

## Gotchas
- For exact per-cell values the source table must be consulted; this page summarizes patterns only.
- Some permissions depend on software package availability.
