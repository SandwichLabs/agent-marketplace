# How to change a teacher's pay rate for a class

Change the pay rate attached to an existing scheduled class through the Change instructor / Make Schedule Change screen. Use it to fix a wrongly chosen rate or apply a new one going forward.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/classic/admmainclass?fl=true
- Menu path: **Classes** in the left navigation

## Steps
1. Open **Classes**; click the **three-dot menu** to the right of the class.
2. Choose **Change instructor**.
3. In "Please select the type of change", pick **Permanent - From date forward**.
4. Tick **Teacher change** and pick the same teacher already assigned in **New Teacher** (pick a different teacher only if swapping instructors).
5. Choose the new **pay rate**.
6. Click **Submit**.

## Gotchas
- **Permanent - All past & future** rewrites the pay rate retroactively from the class's first date; use it only to correct an initial setup mistake, since it changes past payroll. ⚠️ Financial — confirm with the user first.
- Feature depends on software package.
