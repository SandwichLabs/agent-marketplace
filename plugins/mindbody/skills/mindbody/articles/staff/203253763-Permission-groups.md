# How to add and manage permission groups

Permission groups (e.g. "Front Desk", "Therapists") bundle staff permissions so many employees can be configured at once. Use this to create, copy, rename, delete groups, set IP restrictions, and assign staff to a group.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_ss_staff_grp.asp (Edit/Add Groups)
- Staff list: https://clients.mindbodyonline.com/app/staff
- Menu path: **Settings** > **Staff** > **Staff Permissions**, then **Edit/Add Groups** (top right)

## Steps
### Add a group
1. On Edit/Add Groups, type a name in **New Group Name**.
2. Optionally tick **Restrict IP** (only if IP restrictions are enabled).
3. Click **Add**, then **Edit Logins & Permissions** on the new row to set its permissions.

### Copy a group
1. Use the **Select** dropdown to pick the group to copy.
2. Type a **New Group Name**, click **Add**. The copy appears at the top with identical permissions.

### Edit/delete existing groups
- Rename in the **Group name** field, change **Default launch tab**, then click **Update** (top right).
- **Delete Group** link, then confirm with **OK**.
- Check **Enable IP Restrictions** to reveal the **Restrict IP** column; **Setup IP List** edits allowed addresses.

### Assign a group to a staff member
1. Go to **Staff** and click the person's name.
2. If their account isn't set up: **Set up permissions**, enter email, **Next**, choose group in **Role** dropdown, add any extra info, **Done**.
3. If already set up: **Edit permissions**, choose group in **Role**, **Save**.

## Settings & fields
- **Default launch tab**: screen the group's members land on after login (e.g. Classes for instructors, Appointments for therapists, dashboard for managers).

## Gotchas
- Requires the **Administer permission groups** permission (Settings section); same permission covers IP restrictions.
- Three built-in groups exist: Manager, Staff, Webmaster.
- A group named "Owner" cannot be created (owner login already has everything).
- Any single permission difference between staff warrants a separate group; copying is the easy way (e.g. "Front Desk - Payroll").
- Deleting a group is confirmed only by a pop-up; confirm with the user first.
- Some features depend on software package.
