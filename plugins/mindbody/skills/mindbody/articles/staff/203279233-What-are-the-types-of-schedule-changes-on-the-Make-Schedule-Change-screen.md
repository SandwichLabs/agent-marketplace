# The Make Schedule Change screen for classes and courses

Explains the schedule-change types for an already scheduled class or course (teacher, assistant, class, time, room, cancellation) and which type to choose. Needed when swapping teachers, moving times, or cancelling.

## Where in Mindbody
- Class Schedule: https://clients.mindbodyonline.com/app/business/classic/admmainclass?fl=true
- Course Schedule: https://clients.mindbodyonline.com/app/business/asp/adm/main_enroll.asp?fl=true
- Menu path: **Classes** (or **Courses**) > click the class/course name (opens Edit Scheduled Class/Event) > scroll down > **Make Schedule Change**

## Steps
1. Open the class/course, click **Make Schedule Change** at the bottom.
2. Choose the type of change and the detail to change (teacher, assistant, class, time, room).
3. Click **Save**.

## Settings & fields
### Types of change
- **Permanent - All past & future**: rewrites the whole schedule, including past records and payroll. Use for single-day classes or ones scheduled wrongly.
- **Permanent - From date forward**: splits the schedule in two at the chosen date; earlier data untouched; later "All past & future" changes only touch the new schedule. Use for lasting changes or temporary ones like summer hours.
- **Temporary - Date range**: changes only visits in that range; class continues normally outside it.
- **Class/Event cancellation**: early-cancels clients' reservations and shows a summary of cancelled visits.

### Details you can change
- **Teacher change**: pick teacher and pay rate (or change current teacher's rate). Wrong-schedule fix: All past & future (substitutions stay but get updated to the new teacher/rate; affects payroll history). Ongoing new teacher: From date forward. Longer absence: Temporary (fix pay dates for past ranges). One-day absence: use Quick Teacher Substitution.
- **Assistant change**: always uses default Pay Rate 1 (cannot choose another).
- **Class or course change**: switch to another class in the same service category. All past & future only if scheduled in error; From date forward ends the old class and starts a new one. To rename a class use **Services & Products > Classes**, edit **Class name**, **Save**. Temporary swaps still show the original name at top of Edit Scheduled Class/Event, with the new one under Teacher/Class Changes.
- **Time change**: only offered for the two Permanent types. For a temporary time change, remove assigned rooms and use From date forward, e.g. 8-9am Jan-May, 9-10am Jun-Aug, 8-9am Sep-Dec as three schedules.
- **Room/layout change**: temporary only, and only if the class originally had a room and layout. Permanent room change: remove room, add new room, pick layout on Edit Scheduled Class/Event.

### Cancel/delete recommendations
- Single date or date range: three-dot menu beside class > **Cancel or delete class**.
- Permanent end: remove room, change **End date**, reassign room, **Save**.
- Delete: only if scheduled in error and no spots reserved; **Delete** top right.

## Gotchas
- Needs **Manage class/event schedules** permission (Settings section).
- Changes may take 24-48 hours to show in the Mindbody app.
- Detail changes do not touch existing reservations or notify clients. To notify, tag clients on Class Sign In, make a Mailing List, and email externally.
- Changing a class time automatically removes assigned rooms.
- Cancelling a class can be undone but cancelled client reservations are not restored automatically (restore manually via the Cancellations report). Cancellation emails go only to the assigned instructor, not substitutes.
- ⚠️ Irreversible / financial — confirm with the user first: All past & future changes rewrite payroll history, and cancelling a class early-cancels clients (can affect passes/fees).
