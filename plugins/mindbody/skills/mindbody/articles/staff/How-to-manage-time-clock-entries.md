# How to manage time clock entries (add, edit, delete)

Covers fixing staff Time Clock records (used to compute pay): adding a missed entry, correcting one, or removing one made by mistake.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/reports/staff/time-clock
- Menu path: **Insights > Reports**, then search **Time Clock** (or **Staff > Time Clock**)

## Steps
### Add a missing entry
1. Clock the person in or out using the normal clock in/out flow (see [How to clock in and clock out](https://support.mindbodyonline.com/s/article/How-to-clock-in-and-clock-out?language=en_US)); this stamps the entry with the current date/time.
2. Then edit the entry (below) to set the real time.

### Edit an entry
1. Open the Time Clock screen (link or menu path above).
2. Use the filters to pick one or more staff members; click **Generate**.
3. Click **Edit** at the right of the entry.
4. Change clock-in/out time, date, etc.
5. Click **Save**.

### Delete an entry
1. Follow steps 1-3 above, click **Edit** on the entry.
2. Click **Delete** (bottom left).

## Gotchas
- Clock in/out times cannot be set in the future.
- The time clock task field only shows when two or more time clock tasks are active.
- All staff logins can clock in/out by default; extra Time Clock features need Time Clock staff permissions.
- Some features depend on software package.
- Deleting an entry affects pay calculations; confirm with the user first.
