# New Schedule widget v2 setup and options (branded web widgets)

How to create, configure and upgrade to the Schedule widget v2, the modern class/course booking calendar for the studio website, plus its limits.

## Where in Mindbody
- Direct link: https://brandedweb.mindbodyonline.com/ (Branded Web Manager login needed)
- Menu path: **Widgets** (top) > **Create New Widget** > **Schedule Widget**

## Steps
### Create
1. Log in to the Branded Web Manager; click **Widgets**.
2. **Create New Widget** > **Schedule Widget**.
3. Adjust settings (live preview on the right).
4. Click **Save and Deploy** (bottom).
5. Add the code to the website.

### Upgrade a v1 widget
1. Open the v1 widget; click **Preview the New Widget** (bottom left).
2. Adjust customizations; click **Save and Upgrade**. It replaces the old widget on the site automatically.
3. Old v1 widgets stay in the list and keep working, but no new v1 can be created. Deleting a widget is permanent.

## Settings & fields
- **Widget title** (Edit > Widget Title > Submit): internal only, hidden from clients; use specific names if several.
- **Style > Color Scheme**: Primary (primary buttons), Secondary (text links, selected states), Background; hex code or picker. **Button Text**: Book, Sign Up, Reserve, Enroll, Register, or Custom (max 12 characters).
- **Content > Headline**: text at the top of the widget.
- **Content > Select Schedule Contents**: all class types, instructors and locations by default. Narrow via **Class Type**, **Instructor**, **Location** (multi-location sites only): choose "Only the following ..." then check items, **Apply**.
- **Content > Start Date**: today or a future date.
- **Region > Language**; **Clock Format** (12-hour or 24-hour).

## Client experience
- Find a Class calendar; filter by location, class type, instructor; instructor photo/bio; Pick-a-Spot supported when enabled and a room layout is assigned.

## Gotchas
- Does not support: Words and Phrases hotwords, custom CSS, masking instructor names, the "Show on schedule" cancellation setting (cancelled classes are hidden).
- No support for "open courses" or "date forward courses" (per-session pricing).
- Honors the Enable Booking Through Widgets setting on Site Settings; disabling it stops widget booking.
- Capacity is shown only once a class is 80% full.
- Only classes marked Active appear; deactivating a class hides it even if its schedule is active.
- Required-payment classes offer eligible contracts in book-and-buy. Cards save automatically only when buying a contract via the cart; for book-and-buy in cart v1 enable the Missing Billing Information alert with **Force Resolution - Consumer Mode**.
- Mindbody Support will not add code to the website or debug website-specific behavior.
- Features depend on software package.
