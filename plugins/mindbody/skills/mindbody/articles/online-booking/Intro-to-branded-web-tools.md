# How to set up branded web tools

Overview of branded web tools (widgets and smart links that embed Mindbody booking, buying and signup on the studio's own website) and how to create a first widget. Read it before building any website integration.

## Where in Mindbody
- Direct link: https://brandedweb.mindbodyonline.com/users/sign_in (Branded Web Manager, separate from the business software)

## How it works
Create a widget in the Branded Web Manager, copy its code snippet, paste it into a page of the studio's website. The widget talks to Mindbody in real time. Included in the software package.

## Widget types
- **Schedule**: calendar of upcoming classes; sign up with a pass or buy one.
- **Appointment**: find, book, buy or request appointment times.
- **Registration**: new account plus signed liability waiver uploaded to Mindbody; supports custom questions or health intake style.
- **Class List**: each class type with its own description, image, schedule.
- **Enrollment**: courses/workshops/events calendar.
- **Prospect**: creates the person as a prospect; good for "Contact us" lead forms.
- **Staff List**: next month of classes/courses per staff plus public bio and photo; does not link to staff appointments.
- **Pricing**: shows pricing options, add-ons, contracts for online sale; being rolled out in phases to sites with Consumer Identity enabled.
- Suggested starters: classes = Schedule + Registration; appointments = Appointment + Registration; both = all three. No limit on widgets.

## Steps (first widget)
1. Log in to the Branded Web Manager (try the Mindbody software email/password; use **Need new password?** to reset; first-time users get a guided flow).
2. Click **Create New Widget**; pick a type from the dropdown.
3. Review Widget Settings: Style, Content, Filters, Region. Start with defaults ("vanilla").
4. Optionally choose **Modern Style** under Base Style.
5. Preview: Schedule widget shows preview beside settings; other types need **Preview Widget** at bottom.
6. Click **Save**. Widgets can later be edited or deleted.
7. Paste the code into the website builder page; test on a non-public page first or hand to the web developer.

## Smart links (keep clients on the studio site)
- **Login/Register**, **Cart**, **Buy Now - Pricing Options**, **Buy Now - Contracts**, **Gift cards**. Unlike normal Mindbody links (which send clients to the online store), these stay on the studio's site. Put Login|Register in the site header.
- Tip: a page with only the Registration widget on a front-desk tablet replaces paper forms.

## Gotchas
- No single install procedure; builder-specific CSS help comes from the website builder.
- Some features depend on software package.
