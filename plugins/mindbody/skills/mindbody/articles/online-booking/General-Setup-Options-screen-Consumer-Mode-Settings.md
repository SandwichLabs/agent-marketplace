# General Setup & Options screen: Consumer Mode Settings

Reference for the Consumer Mode Settings section of General Setup & Options, which controls what clients can do on the online consumer site (sign-up, billing info, booking windows).

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_ss_setup.asp
- Menu path: **Settings > General > General Setup & Options**, then expand **Consumer Mode Settings**

## Steps
1. Open General Setup & Options (**Expand All** / **Collapse All** top right helps; browser find works on setting names).
2. Change settings in the section and click **Update** to save before leaving.

## Settings & fields
- **Allow New Clients to Create Accounts**: Enabled lets anyone create an account online (and use "Need new password" if an email is on file). Disabled blocks consumer-site sign-ups only; branded web tools and the Mindbody app still allow them, and branded app sign-up is controlled in the Branded App Portal.
- **Billing Info - Store Automatically**: Enabled auto-stores cards on consumer-site purchases (clients can still tick **Store Billing Information**). Disabled: store manually via the **Store Billing Information** checkbox at Point of Sale with CC (Swiped).
- **Allow Clients with Autopays to Edit Billing Info**: **Always**; **Only when expiration within X month(s)** (1-4 months); **Never**.
- **Allow Clients to book Appointments/Reservations for Other Clients**: off by default. When on, bookings for others use a placeholder account ("Reserve, Reserve"). May be grayed out (see Book Multiple article).
- **Location - Update on Login**: assigns the chosen location at login only if the client has none on their Client Info screen. Multi-location (datashare) sites only.
- **Scheduling Cutoff for Same Day Services**: **Not Used**, or **Select Time** after which same-day booking closes (times come from Scheduling Increments across client views).
- **Scheduling Hours**: **24 hours per day** or **Custom** (set Scheduling Start Time and Scheduling End Time).
- **Scheduling Start Time**: time of day the booking window opens for classes; days ahead is set in Class and Course Options. Example: class 8am Jan 15, window 3 days, start 6am gives booking from Jan 12 6am.
- **Display pricing option description online**: shows Service Notes during online purchase when enabled.
- **Show Home Studio in Sign Up Form**: adds a most-visited-location dropdown to sign-up.
- **Show Client Purchase History in Consumer Mode**: on by default; adds a Purchases screen to My Info. Off means clients must ask the business.

## Gotchas
- Visible settings vary by package and by other enabled settings; disabling one can hide others.
- Booking for other clients: purchases attach to the placeholder account and the real client record is lost unless you assign the correct profile before checkout. The "Registered!" message no longer appears when this is on.
- Choosing Custom for Scheduling Hours disables the "Class Time-Based Booking" field in Class and Course Options.
