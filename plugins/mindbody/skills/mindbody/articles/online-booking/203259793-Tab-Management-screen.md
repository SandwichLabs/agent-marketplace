# Client View Settings screen

Controls which service tabs (classes, courses, appointments, media, links) clients see on the Mindbody consumer site, what they are called and their order. Use it when a service category is missing or tabs need renaming, hiding or reordering.

## Where in Mindbody
- Direct links: https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_tg_tabs_v2.asp (Client View Settings); https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_tg.asp (Service Categories)
- Menu path: **Settings > General > Client View Settings**; **Settings > Classic Setup > Service Categories**

## Steps
### Edit the Client Views (default tabs)
1. Open Client View Settings.
2. In Client Views, adjust **Updated Name**, **Show/Hide** and **Order**; save.

### Add a Custom View
1. Scroll to **Add a Custom View**.
2. Enter a **Name** and select a **Type**: Classes, Courses, Appointments, Media (consumer site only) or Link (consumer site only).
3. Click **Add**, then scroll to Custom Views.
4. Classes/Courses/Appointments: open **Service Categories**, tick the categories, click **Save**, then **Edit Scheduling Increments** to set bookable times.
5. Link: enter the destination URL in **Service Categories** and **Save**.
6. Media: follow the Media Management article.

### Edit or delete a Custom View
1. Scroll to **Custom Views** and change **Name**, **Type**, **Service Categories**, or the link.
2. **Edit Scheduling Increments** opens that screen; **Delete** removes the view.
3. Click **Save** (bottom right).

### Fix a missing service category
1. Open **Service Categories** (Classic Setup).
2. Find the category and set the correct tab in **Tabs this Service Category is on**.
3. Click **Save**.

## Settings & fields
- **Default Name**: the stock tab name.
- **Updated Name**: display name, up to 30 characters.
- **Show/Hide**: checkbox; some views are hidden by default and have no checkbox.
- **Order**: 0 is far left, higher goes right.

## Gotchas
- Needs the Service Categories screen permission (Settings). Availability depends on software package.
- Default Views (classes, courses, appointments) cannot be removed, only renamed or hidden; their hours are set on Scheduling Increments.
- To change only what clients see, edit **Updated Name** rather than the Custom View name.
- In the Mindbody app and branded web tools clients pick a service category, not a tab; booking times follow scheduling increments.
- This is not the business site's navigation menu (separate article) or the branded app's tabs.
- Delete on a Custom View removes it outright; confirm with the user first.
