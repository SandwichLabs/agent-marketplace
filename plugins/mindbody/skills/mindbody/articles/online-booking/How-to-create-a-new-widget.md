# How to create a new widget (branded web widgets)

Generic procedure for creating any branded web widget except the redesigned Schedule widget, which has its own setup. The example in the source is an Appointment widget.

## Where in Mindbody
- Direct link: Branded Web Manager login (the article links http://manager.healcode.com/users/sign_in; the intro article uses https://brandedweb.mindbodyonline.com/users/sign_in)
- Menu path: **Widgets** at the top of the manager

## Steps
1. Log in to the Branded Web Manager and click **Widgets**.
2. Click **Create New Widget** and pick a type from the dropdown.
3. Enter a widget title; fill in optional details (options vary per type).
4. Scroll to the bottom and click **Save**.
5. Copy the generated code onto the website or give it to the web developer.

## Customizing
- Custom CSS for finer styling.
- Colors by hex code or color wheel (Schedule widget has a different color view).
- **Advanced Options**: extra filters such as showing only certain teachers (Schedule widget has none).
- **Preview Widget** shows the result after each change.

## Widget types
- **Appointment**: search, buy, book/request appointments.
- **Class List**: each class separately with description and schedule.
- **Enrollment**: upcoming enrollments up to 12 months ahead.
- **Prospect**: creates account flagged as prospect (contact forms).
- **Registration**: new account signup.
- **Schedule**: classes and enrollments together; book with pass or buy.
- **Staff List**: chosen staff with public bios and photos.
- **Pricing**: pricing options and contracts; phased rollout to sites with Consumer Identity.

## Gotchas
- The Schedule widget does not follow this procedure (new look, different options).
- Features depend on software package.
