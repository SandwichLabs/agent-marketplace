# Appointment Options screen: Directory

Index of the settings screen that governs how appointments are booked, paid for, cancelled and displayed. Use it to locate which section a given appointment setting lives in.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_ss_appt.asp
- Menu path: **Settings > Services > Appointment Options**

## Settings & fields
Two collapsible sections (**Expand All** / **Collapse All** top right; **Update** saves).

**Appointment System Policies**
- General settings: allow client-booked appointments; require client payment at booking; appointment waitlist (plus First to Claim automation and client self-waitlisting); auto load selected client; payment buttons in Business Mode; appointment checkout review; track confirmations and arrivals; confirmation/cancellation numbers; gender preferences (use, require at booking, store); session type levels; smart booking times; start by booking time; browse schedule in Consumer Mode; Consumer Mode default load option; first-available-only booking; restrict client booking to bold times; pay instructors for late-cancelled appointments; back bar charge; prep and finish time; sign-in/self sign-in checkout; duplicate/overlapping appointments; do not restrict staff to one session type after booking; default require resource; separate resource per client in multi-capacity appointments; allow rescheduling in Consumer Mode.
- **Schedule Window Type** and **Schedule Windows**: how far ahead clients may book.
- **Cancellation Windows**.
- Additional: block size on first load, schedule booking snapping interval, appointment travel sheets, appointment formula notes.

**Appointment Schedule Appearance**
- Default schedule version, day/week default view, default block sizing, instructor multi-select dropdown, instructor name ordering, show appointments / day view in Consumer Mode, service category menu, gender filters, client names on booked appointments, category/type/room names in Daily - All Instructor view, current series in single-instructor view, appointment notes, unavailability start times, client name format, color coding system, max instructors per page, schedule background and timeline colors.

## Gotchas
- Staff need the **Appointment Options Screen** permission (Settings section) to change anything.
- Some features depend on the software package.
- Changes are lost unless **Update** is clicked.
