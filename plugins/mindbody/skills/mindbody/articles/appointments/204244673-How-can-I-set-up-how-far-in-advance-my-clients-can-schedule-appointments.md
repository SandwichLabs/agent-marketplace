# Appointments: How to set up Schedule Windows

Controls how far ahead, and how close to start time, clients can book appointments online. Set per appointment service category.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_ss_appt.asp
- Menu path: **Settings > Services > Appointment Options > Appointment System Policies > Schedule Windows**

## Steps
1. Open **Appointment Options** (search in Settings or Services menu).
2. Expand **Appointment System Policies**, scroll to **Schedule Windows**.
3. For each service category set **Starts** and **Closes**.
4. Click **Update** (top of that section).

## Settings & fields
- **Starts**: days ahead clients can book. 0 = up to the end of created availability. Example: 7 = one week ahead. The window opens daily at 12:00 AM by default; changeable via General Setup and Options > Consumer Mode Settings.
- **Closes**: minutes before start when booking stops. 0 = last minute. Example: 30 means a 12:30 slot must be booked by 12:00. With bold-time restriction at 15-minute increments and Closes 30, after 12:00 passes the next bookable slot is 12:45.

## Gotchas
- Needs the **Appointment Options screen** staff permission.
- Applies to every appointment in that service category; categories can differ.
- Class/course windows are configured elsewhere.
