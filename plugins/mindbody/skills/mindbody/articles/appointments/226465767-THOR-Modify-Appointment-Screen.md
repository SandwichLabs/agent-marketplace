# Modify Appointment screen

Full-detail editor for an existing appointment: change client, instructor, type, date/time/length, room, notes, add-ons, apply payment or check out. Use when the quick sidebar edits on the Appointment Schedule are not enough.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/mainappointments/index
- Menu path: **Appointments** > click appointment > action menu > **Modify**

## Steps
1. Open **Appointments**, click the appointment.
2. In the action menu click **Modify**.
3. Edit fields, then click **Update and Close**.

## Settings & fields
**Top subtabs:** Client Info, Contact Logs, Schedule, Visits, Purchases, Account Details, Documents.

**Quick tasks:** **Print Tip Slip** (appears after Arrived, for prepaid), **Print Travel Sheet**, **Reschedule**, **Early Cancel** (confirm in pop-up), **Update and Close**, **Arrived** and **Confirmed** checkboxes (each refreshes and returns to the schedule).

**Client:** name (opens Client Info), **[Modify]** link to switch to a different client (for wrong-account bookings), phone, email, **Choose an image** / **Delete** profile photo.

**Appointment:**
- **Instructor/Therapist** dropdown (or the Change Instructor list), **Instructor requested** checkbox, **[View schedule]**.
- **Service category**, **Appointment Type**.
- **Override appointment length** (enables editing start/end), **Edit booking time** (changes the staff member's default length for future bookings), **Start time**, **End time** (auto-updates), **Date**.
- **Gender preference** (if feature enabled), **Room**, **Notes**, **Formula notes** (type then **Add**; red X removes; cross-regional notes deletable only at original studio).
- **Booked** and **Last Modified** stamps (modification = time or type change; confirming does not count).

**Change Instructor / Add-ons / Series:**
- **Change Instructor**: other staff offering the same service with their same-day booking counts; click to switch.
- **Add-ons**: choose add-on and instructor, **Add**; red X cancels.
- **Current Series**: shows a pricing option that can pay and its expiration.
- **Override appointment type rules**: use a pricing option that doesn't normally cover the appointment (must be same/related service category).
- **Payment applied**, **Apply payment**, **Completed**, **Check Out**.

## Gotchas
- Only UNPAID appointments can be modified; if payment is applied, early cancel and rebook.
- Location cannot be edited; early cancel and rebook at the other location.
- Staff need the appointment permissions to modify.
- ⚠️ Irreversible / financial — confirm with the user first: Early Cancel, Apply payment (deducts a session), Check Out, Override appointment type rules.
- Edit booking time changes defaults for future bookings, not just this appointment.
