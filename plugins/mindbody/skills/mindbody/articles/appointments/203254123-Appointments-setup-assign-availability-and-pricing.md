# How to add appointment services (add, assign availability, and price)

Creating appointment types (the bookable services under a service category, e.g. "60-minute Signature Facial"), editing them, and handling per-staff prices and booking times.

## Where in Mindbody
- Appointments: https://clients.mindbodyonline.com/app/services-products/appointment-types (**Services & Products** > **Appointments**)
- Staff: https://clients.mindbodyonline.com/app/staff

## Steps
### Add an appointment type
1. **Services & Products** > **Appointments**; find the service category.
2. Click the **Add** dropdown beside the category and choose **Appointment** (choose Add-on for add-ons).
3. Fill in the fields below and save.

### Edit
1. Open the category, click the appointment name, change fields on Edit appointment type, **Save**.

### Per-staff prices (only if Per Staff Pricing is enabled)
1. **Staff** > pick the person > **Staff Appointment Setup** > click the type's price field > enter price > **Save**. (Enabling the feature requires contacting Mindbody support.)

### Fix a stale default booking time
1. Open the appointment type > **Assign Staff** (right side), edit each staff member's booking time, click outside the field; autosaves. Changing the type default does not update staff already assigned.

## Settings & fields
(* = required)
- **Name***, **Duration in minutes***.
- **Price for a single session*** or tick **Add pricing later**; **Revenue category*** (match service category name; **Add New** inline).
- **Sales tax or other**: tax rates in use.
- **Would you like to allow your clients to book this appointment online**: Yes publishes to consumer site, apps, branded tools; **Online description** (plain text only, formatting stripped, no undo/redo).
- **Is this appointment an add-on**, **Color** (needs Color Coding set to "Color Booked by Appointment Type"), **Capacity*** (default 1), **# Deducted***, **Sort order*** (0 for all = by staff then alphabetical; 1 = top), **Back Bar Charge** and **CPT Code** (appear only if those features are enabled).

## Gotchas
- Add only individually bookable services here; packages like "ten-pack" are pricing options, not appointment types. Multi-session passes go in pricing, then packages/contracts.
- Set up revenue categories first.
- Rental equipment/rooms are not appointment types here; use Rooms and Resources.
- Appointment category/subcategory choices help online discovery.
- After creating, confirm the service category is assigned to an Appointments navigation menu item.
- Staff-to-service mapping is done in the staff profile/appointment setup, not here.
- Some features depend on software package.
