# Client Autopay Schedule screen

Lists a client's upcoming autopays and lets staff change dates, amounts, locations and payment methods, run them early, or delete them. Needed for fixing a failed or wrong autopay.

## Where in Mindbody
- Menu path: client's **Account Details** > **Autopay Schedule** (upper right); or **Client Info** > Billing Information > **Autopay Schedule**
- Return to Account Details with **Summary** (top left).

## Steps
### Edit scheduled autopays
1. Open the Autopay Schedule, edit date, amount, location or payment method in the rows (check the row for edits to scheduled or declined ones).
2. Click **Update**.

### Run now / remove
1. Tick checkboxes (or **Check all** / **Uncheck all**).
2. Click **Run All Checked Transactions Now** (charges instantly) or **Remove Checked Transactions** (deletes, so they never run).

## Settings & fields
- **Schedule Date**: editable (not for suspended contract autopays).
- **Amount** (pre-tax), **Tax**, **Charge Amount** (after tax): Amount editable under tax-exclusive pricing; Charge Amount editable under tax-inclusive pricing.
- **Description**, **Location** (dropdown; affects Sales report), **Payment Method** (card, ACH, direct debit, debit client account).
- **Apply to All?**: copies the first chosen payment method to every row.
- **Contract**: blank means a staff member set the autopay up manually.
- **Status**: Scheduled, Scheduled after suspension (fixed-period suspension), Suspended (open-ended), Submitted (red; did not fully run, needs Merchant Support), plus accepted/declined.
- **Warning triangle**: hover for who changed it last and when.

## Gotchas
- ⚠️ Irreversible / financial — confirm with the user first: **Run All Checked Transactions Now** charges the client immediately (each has its own sale ID and processing fee, refundable individually); **Remove Checked Transactions** prevents payments from running.
- Permissions: View AutoPay schedule and history, View client account/purchase history, Edit autopay details (Clients); Ability to view all clients (Sales Team Management); Run autopays (Payment Processing).
- Suspended transactions cannot be edited here; edit the suspension instead.
- Month-to-month contracts only offer Run Now for the next month.
- Contracts renewing "When the pricing options run out" show date "AUTO".
- Autopays added via Add New Autopay Schedule appear here but not on Account Details (only contracts do).
- Failed ACH, SEPA, PAD or Direct Debit autopays automatically convert to the account (debit) payment method.
