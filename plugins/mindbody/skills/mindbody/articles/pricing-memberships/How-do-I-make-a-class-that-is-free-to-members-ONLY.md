# How to make a class that is free to members only

Three ways to give members free classes: a members-only service category, a free class that non-members can pay for, or a restricted free pricing option.

## Where in Mindbody
- Classes: https://clients.mindbodyonline.com/app/business/servicesandpricing/Classes (Services & Products > Classes)
- Membership Settings: https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_ss_membership.asp (Settings > Clients > Membership Settings)

## Steps
### A. Members-only free service category
1. Services & Products > Classes > **Add service category**; three-dot menu > **Rename service category** (e.g. "Member Classes").
2. Settings > Clients > Membership Settings; choose the tier in **Select Membership Tier**; in **Online Booking Restricted to Our Members Only** select the new category; **Save**. Repeat for every membership that should book it (Ctrl/Cmd-click for multiple).
3. Schedule classes in the category (see class setup article) and tick **Clients can attend this class for free**.
   - Booking sells the client a Free Class pricing option, usable only for these classes, which disappears if they cancel.

### B. Free for members, paid for non-members
- Relate service categories so members' pricing options in one category pay for another's classes (pricing relationships).
- If only one class in a category is free, move/recreate it in its own category so special pricing can apply.

### C. Free pricing option restricted to members
1. Classes > category > **Add Pricing** > **Single Session**; fill in basics (price 0).
2. **Additional options** > "Need to set up advanced settings" **Yes** > **Add with Additional Options**.
3. Expand **Advanced Settings**; in **Restrict to members only** select the memberships (Ctrl/Cmd-click; deselect all to remove restriction).
4. **Save**.

## Gotchas
- Staff permissions needed: Membership Setup screen, View Services & Pricing, Edit pricing option details/price/name, Add and deactivate pricing options, Manage account credits/gift cards/contracts/packages, Item/membership discounts & restrictions, plus Ability to view all clients.
- With branded web tools, use option C so only members can attend the free class.
- Restrictions are per membership; forgetting to add a second tier locks that tier out.
