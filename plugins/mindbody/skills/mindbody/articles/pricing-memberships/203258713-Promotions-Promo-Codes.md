# Promo Codes screen

Create, edit, deactivate and reactivate promo codes (flat or percentage discounts for products and services). Use it when a studio wants a code for a sale or intro deal.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_promotion.asp
- Menu path: Settings > Pricing > Promo Codes

## Steps
### Create
1. Open Promo Codes, click **+Add New** (top right).
2. Fill in the settings below, then click **Add** (bottom left).

### Deactivate
1. Open the code and clear the **Active** checkbox (it moves to the inactive list).

### Reactivate / find inactive
1. Set the status dropdown to **Inactive** (or **All Status**) and click **Apply**; optionally use the Expired filter.
2. Tick the **Active** checkbox on the code's row.

## Settings & fields
- **Promotion name**: appears in reports only.
- **Promotion code**: what staff/clients type; max 50 characters, not case-sensitive; **Generate** makes one.
- **Discount type** (Percent or Amount) and **Discount amount**.
- **Exclude from online checkout**: staff-only redemption.
- **Max uses per client**: unlimited, single, or custom; each transaction counts once regardless of items.
- **Define promotional items**: default is everything. Narrow by **Revenue Category** (use this to discount gift cards), **Brand / Supplier**, **Service Category**, **Retail Products**, or individual **Pricing option**; repeat to add several. Inactive pricing options are not listed.
- **Activation date** / **Expiration date** (last usable day, valid until 11:59pm).
- **Days after close date**: only with Sales Team Management; leave Unlimited if prospects or sales reps are unused.
- **Valid day(s)**: weekdays the code can be redeemed on in the online store (not the class day).
- **Apply discount on autopays**: unchecked discounts all autopays of a contract; checked reveals **Number of Autopays** (e.g. 3 = first three).

## Gotchas
- Staff need "Set up promotions/semester discounts" permission.
- No membership restriction or cap on how many clients can know the code.
- Contracts with promo codes in branded web tools require the new consumer cart v2 / checkout.
- On packages, a promo code overrides the package discount and discounts each item individually (percentage applies to original total; a flat amount is taken off each item, floor 0). Unless items are contract/package-only, the code also works on those items separately.
