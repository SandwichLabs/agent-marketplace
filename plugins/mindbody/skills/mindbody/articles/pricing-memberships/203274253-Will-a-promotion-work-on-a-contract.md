# How to set up and use promo codes for contract sales

How to build a promo code that discounts the autopays of a contract and apply it when selling that contract at Point of Sale.

## Where in Mindbody
- Promo Codes: https://clients.mindbodyonline.com/app/services-products/promo-codes (Settings > Pricing > Promo Codes)
- Point of Sale: https://clients.mindbodyonline.com/app/business/asp/adm/main_retail.asp?fl=true&tabID=3

## Steps
### Create the promotion
1. Settings > Pricing > Promo Codes; pick an existing code or **+Add Promo Code**.
2. Fill in standard promo settings.
3. In Applicable Items choose **Pricing Options** and search for the pricing option inside the contract (not the contract name).
4. In Advanced tick **Apply discount on autopays** and enter how many autopays to discount (3 = first three; 1 = only the initial sale at POS).
5. Click **Add**.

### Apply at Point of Sale
1. Point of Sale > select the client.
2. Click **Contracts / Packages**, choose the contract, click **Add item**.
3. Type the code in **PROMOTION CODE**, click **Apply**; the discount shows on the ticket.
4. Choose payment method and receipt option. The Autopay Schedule then shows the discounted autopays.

## Gotchas
- Registration fees made inside contract settings are not selectable as items; to discount one, create it as a product and add it as a one-time item. Account payments are not selectable, so codes cannot discount account credits.
- Branded web tools need consumer cart v2/checkout; promo codes do not work on Buy Now - Contract links (cart v1).
- Inactive pricing options do not appear in Applicable Items; reactivate or target the revenue/service category.
- Without the autopay setting the code still works at POS but discounts all autopays.
- No stacking; order applied: promotions, contracts, early bird, membership discounts.
- Discounted autopay count cannot exceed the contract's autopays, else error "Invalid Promocode. Exceeding discount autopay count."
- Month-to-month contracts: codes only cover the first two months of autopays; more triggers the same error.
- With no promotional items defined, the discount applies to the client's whole purchase.
