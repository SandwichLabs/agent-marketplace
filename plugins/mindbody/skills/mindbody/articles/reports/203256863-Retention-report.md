# Retention report

Counts clients who had an initial visit (class, course or appointment) in a date window and then came back within N days, split into new, repeat and total. Use it to judge new-client retention or the payoff of a promotion.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_rpt_retention.asp?category=Clients
- Menu path: **Insights > Reports**, search "Retention" or go to **Clients > Retention**

## Steps
1. Open the report.
2. Set the initial-visit date range, locations, service categories, return window and view.
3. Click **Generate**.

## Settings & fields
- **Initial Visit to**: location of the first visit (Any Location for all).
- **Initial Visit between [date] and [date]**: default starts three months before today and spans one month. Quick dates: **Calendar Months**, **To-Date**, **Rolling Averages**.
- **Service category**: multi-select (Ctrl/Cmd-click or drag); filters the initial visit's category.
- **With** (first): limit to clients whose first visit was with one instructor; lists only staff with initial visits in the range.
- **Returned to**: location counted for return visits.
- **Within [number] days**: return window after the initial visit.
- **With** (second): Any Instructor or The Same Instructor for the return visit.
- **Repeat Clients Based on**: Any Instructor/Any Location, Any Instructor/Same Location, Same Instructor/Any Location, or Same Instructor/Same Location; decides who counts as repeat rather than new.
- **View**: Summary (numbers and percentages only) or Detail (adds client names; a name opens that client's Visits screen).
- **Tagged clients only**, **Generate**, **Export to Excel**, **Tag add**, **Tag new** (replaces tagged list, no clients removed), **Save this report**, **Print this report**.
- Result terms: Repeat Clients (visited before the range, then again inside it); Repeat Clients Retained (plus a further visit within the window); New Clients (first-ever visit in the category fell in the range); New Clients Retained; Total Clients; Total Clients retained; retention rates are retained divided by group, times 100.

## Gotchas
- Needs Marketing Reports and Analysis Reports permissions; availability depends on software package.
- If an instructor is missing from the **With** menu, widen the initial-visit dates, click **Generate**, then reopen the menu.
- Retention is measured within the service category selected.
- Example from the source: 28 initial visits, 10 retained (35.71%).
