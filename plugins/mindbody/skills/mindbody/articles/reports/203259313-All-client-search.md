# How to create and export a list of clients using the Client Directory

Shows how to list all (or tagged) clients in the Client Directory and get that list into Excel. Use it for quick client lists under 1,000 rows.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_clt_lkup.asp
- Menu path: **Clients** in the left navigation

## Steps
### List all clients
1. Open **Clients**.
2. Leave the search field blank and click **Search**.
3. Scroll to the bottom to see the total count, or use the tag options to tag them for a mailing list.

### List tagged clients
1. Open **Clients** and expand **Filters**.
2. Tick **Tagged clients only** (the number in parentheses is the current tagged total).
3. Click **Search**.

### Export to Excel (copy and paste)
1. Generate the list.
2. Highlight the results table and copy it (Ctrl+C / Cmd+C).
3. Paste into a blank spreadsheet (Ctrl+V / Cmd+V).
4. Delete the first two rows, which hold numbers and member icons.

## Settings & fields
- Pasted columns: Name, ID, Birthday, Age, Emergency contact name, Phone, Address, Email, Username.
- Alternative: tag the clients, build a list in the Mailing Lists report, then use that report's **Export to Excel**.

## Gotchas
- The Client Directory has no built-in export button.
- It shows at most 1,000 matching clients; for larger databases use the Mailing Lists report or narrow the filters.
- Needs Ability to view all clients and View client info permissions. Availability depends on software package.
