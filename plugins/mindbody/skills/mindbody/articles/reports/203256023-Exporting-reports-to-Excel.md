# How to export reports to Microsoft Excel

Nearly all Mindbody reports can be downloaded as Excel files. Use this when a user wants report data in a spreadsheet.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/reportslandingpage/FavoriteReports
- Menu path: **Insights** > **Reports**

## Steps
1. Open **Insights** > **Reports** and run/open the report.
2. Click the **Export to Excel** icon.
3. Save the downloaded file when prompted.

## Gotchas
- No icon means that report cannot be exported.
- Staff need the **Export report information** permission (Reports section).
- Blank reports on Windows: disable Excel Protected View.
- Exports are not print-ready; adjust column widths/font or use Excel's Print to Fit.
- Browser extensions can freeze exports (see browser requirements article).
- Google Sheets/Numbers workaround: rename the exported file from .xls to .html, open it, copy/paste. Unsupported by Mindbody and unreliable.
- Excel files can be imported into accounting tools like QuickBooks (follow that tool's help).
- Some features depend on software package.
