# How to create a mailing list of all active clients

Two ways to produce a list of clients with an active profile: the Mailing Lists report (for a mailing list) or the Client Directory (for a plain list or tagging). The article only gives the filter values and defers the steps to other articles.

## Steps
### Option A: Mailing Lists report
1. Run the Mailing Lists report (first-run steps are in the Mailing Lists article).
2. Set the **List clients** filter to **Currently active**.

### Option B: Client Directory
1. Follow the Client Directory list-generation steps (All client search article).
2. Set the **Client info** filter to **Active clients**. Use this to tag clients for other reports.

## Gotchas
- "Active" means an active profile, not an active membership. For active members use the separate active-members mailing list article.
- Reports available depend on software package.
- Tagged clients can be exported to Excel or fed into the Mailing Lists report.
