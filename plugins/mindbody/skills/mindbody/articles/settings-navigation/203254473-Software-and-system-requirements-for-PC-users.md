# Mindbody software computer and browser requirements

What computers and browsers the Mindbody business software supports, plus a checklist for when screens fail to load or misbehave. Useful for an agent diagnosing browser-side problems.

## Settings & fields
Supported environment
- Any modern desktop or laptop with the latest Chrome, Safari, or Firefox (non-mobile builds).
- Windows 7 or newer with updates (XP unsupported); Internet Explorer unsupported; Chrome recommended on Windows.
- Mac: an OS version still receiving security updates; Chrome, Firefox, or Safari.
- Minimum versions listed: Chrome 74+ (up to 125+ for the 2025 era), Firefox 68+ (to 125+), Safari 17+ (to 19+). Newest versions are strongly advised.

Receipt printing
- Works in any browser with Mindbody-sold printers, but Firefox or Safari give better results than Chrome.
- Automatic printing is poorly supported; if the printer misbehaves, turn off **Receipts - Print Automatically**.
- Firefox print problems on Windows: adjust printer margins.

Online booking (clients)
- Any device, cookies must be enabled, broadband recommended.
- Livestream browser/device support has its own troubleshooting FAQ.

## Gotchas
Troubleshooting checklist when a screen won't load or acts oddly:
- Update the browser; clear the cache.
- Check plugin compatibility (Java matters for Point of Sale and connected hardware).
- Do not bookmark staff login pages (URLs change).
- Turn off browser autofill (login and billing screens misbehave).
- Disable extensions one at a time (they can freeze screens, especially report exports to Excel; Norton Confidential is a known cause).
- Allow pop-ups (some screens open in pop-ups).
- Reset zoom to 100% if screens jitter (notably Chrome).
- Large reports can time out; browser/OS timeout settings can be raised.
- Last resorts: close and reopen the browser, restart the computer, try another supported browser.
- Phones, tablets, and Chromebooks are not recommended for setup or management (Java is typically unsupported there); use the Mindbody Business app for on-the-go tasks.
- Some features depend on software package.
