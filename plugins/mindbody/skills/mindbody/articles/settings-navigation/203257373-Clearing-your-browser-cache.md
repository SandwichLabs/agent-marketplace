# Clearing your browser cache

Generic fix when the Mindbody site behaves oddly after changes. Recommended after software-level changes, staff permission changes, ISP outages or modem/hardware failure.

## Steps
- **Always first**: log out of the Mindbody site.
- **PC**: Chrome, Edge and Firefox each follow the browser vendor's own clear-cache/cookies instructions. Shortcut **Ctrl + Shift + Delete** opens the clear-data dialog.
- **Mac Chrome/Firefox**: vendor instructions, or **Command + Shift + Delete**.
- **Mac Safari**: **Safari > Settings > Privacy > Manage Website Data**, then **Remove** items or **Remove All**; or clear history via Apple's guidance. Shortcut **Option + Command + E** clears the cache silently (needs the Develop menu: **Safari > Settings > Advanced > Show features for web developers**).
- **Mobile Safari**: **Settings > Safari > Clear history and website data > Clear History and data**.
- **Mobile Chrome**: three-dot menu > **History > Clear Browsing data**, select **Cached images and files**, confirm.
- **Mobile Firefox**: three-line menu > **Settings > Clear Private Data**, toggle types, confirm.

## Gotchas
- Mobile Firefox's clear action closes all open tabs.
- Related: location default for multi-location staff is browser-stored and lost when cache is cleared.
