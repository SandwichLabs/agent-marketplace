# How to edit the navigation menu on my site

Customize the left navigation panel in business mode: add schedule shortcuts, reorder, hide items, and add external or internal links.

## Where in Mindbody
- Menu path: **Edit** button at the bottom of the left navigation panel opens the Edit Navigation Menu modal.

## Steps
### Add a menu item (booking schedule view)
1. Click **Edit**, then **Add Menu Item**.
2. Choose an **Item Type** (e.g. Appointments, Classes, Courses, Rooms).
3. Select one or more Service Categories to show.
4. Enter a title and click **Create**. A green "New" tag marks it.
5. Click **Save Changes** (bottom right). The new item then lists only items in the chosen categories.

### Add a custom link
1. **Edit > Add new menu item**, set Item Type to **Link**.
2. Paste or type the address in **URL Link** and enter a **Title**, click **Create**.
3. It appears under a **Custom Links** dropdown; click **Save Changes**.

### Manage existing items
- Drag the six-dot icon to reorder.
- Toggle to show or hide an item.
- Three-dot menu: **Edit** (rename) or **Remove** (delete items you created).
- **MANAGE** link opens the client-facing (consumer mode) view settings.

## Gotchas
- Requires the Settings "Services Categories screen" permission; package-dependent.
- Home and everything below the divider line (Clients, Point of Sale, etc.) cannot be customized.
- Max 15 booking items shown at once; hide one to show another.
- Custom Links holds up to five links (Mindbody screens or external sites).
- Remove cannot be undone; recreate if deleted by mistake.
- Changes apply to business mode and staff logins only, not clients' consumer mode.
- If an expected class/appointment is missing from a custom view, check its service category assignment.
