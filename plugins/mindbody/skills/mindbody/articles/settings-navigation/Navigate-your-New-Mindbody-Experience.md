# Navigating your new Mindbody site

Tour of the left navigation panel in the business software and what each item opens. Useful for orienting an agent after login or when a menu item seems to be missing.

## Where in Mindbody
- Menu path: left-side navigation panel; **Edit** button at its bottom opens Edit Navigation Menu.
- Direct link: none given for the panel itself.

## Settings & fields
Menu items, top (customizable) half:
- **Dashboard**: owner-only business insights. Staff logins land on their daily calendar schedule instead. Includes a Messenger widget only if the business has or is eligible for Messenger; "Unavailable"/"Not Available" there means an outage or not yet provisioned (contact Support).
- **Classes**: Class Schedule (book clients, check out, edit classes) and Class Sign In screens.
- **Appointments**: Appointment Schedule (book, modify, cancel, check in/out).
- **Courses**: Course Schedule for enrollments/workshops; also Advance Course Management.
- **Rooms**: room and resource calendar; rentals, equipment reservations.
- **Check In**: Client Check In screen.
Lower (not customizable, below the divider):
- **Clients**: Client Directory, Client Info screen, default client lookup landing page.
- **Point of Sale**: sell services/products, gift cards; "More" dropdown (top right) has Payment Methods and Payments Portal.
- **Insights**: Reports, Analytics, Sales Funnel Analytics, Client Acquisition, Retention Marketing.
- **Marketing**: Marketing Suite (Dynamic Pricing, FAQ), Lead Management, add-ons (branded app, branded web tools, Integrations, Mindbody Capital).
- **Services & Products**: Classes, Appointments, Courses, Video (on-demand, livestream), Retail Products, Pricing, Arrivals, Contracts.
- **Payments Portal**: hub for Mindbody Payments businesses in supported regions, houses Payouts report.
- **Staff**: Staff members screen, profiles, login credentials, password resets, owner login.
- **Custom links**: appears under Staff only after you create one; any internal/external URL.
- **Apps & Integrations**: hub for add-ons and existing integrations (Branded App, Mindbody Insurance, etc.).
- **Settings**: library of links to all settings.

## Steps
### Customize the menu
1. Click **Edit** at the bottom of the navigation panel.
2. Rename or reorder booking menu items, turn hidden screens on, add custom filtered views (classes, appointments, courses, rooms), or create custom links.

## Gotchas
- If an expected screen is missing, enable it in Edit Navigation Menu.
- **Check In** is hidden by default if no service categories are set up for arrivals; turn it on via Edit.
- Self Check In lets clients sign themselves in when desk staff are short.
- Some features depend on software package.
