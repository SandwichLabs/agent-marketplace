# Feature comparison: Messenger vs. Messenger[ai]

Quick reference for which messaging features belong to plain Messenger and which require Messenger[ai]. Use it to tell whether a feature the user wants exists on their plan.

## Settings & fields
- **Messenger**: messaging only, no AI assistant. Real-time SMS chat with clients; clients cannot book or buy through it. No missed-call text.
- **Messenger[ai]**: messaging plus an AI assistant that books, browses, and sells 24/7 and answers missed calls.

Features in both:
- Dashboard: web app, mobile app, unlimited users.
- Texting: unlimited SMS, Broadcast (mass texting), staff messaging, saved replies, MMS (images/docs), business contact card, Hosted SMS (landline).
- Credit card collection.
- Multi-location: global brand settings, roles and permissions, dashboards across locations.

Messenger[ai] only:
- Dashboard: reporting, task management.
- AI automation: AI booking assistant, unlimited appointment and class bookings, missed call text, FAQ triggers, smart rescheduling, customizable AI responses, automated contactless check-in, automated reminder texts, automated follow-ups (rebook, first-class visitor, post-appointment), AI membership and package sales.
- Webchat: webchat widget, intro options on the welcome message.
- Integration: seamless checkout via text.

## Gotchas
- Features depend on software package or add-on; manager permission is needed to change these settings.
