# How to create and manage a configurable sales pipeline (Lead Management)

Create a custom-staged sales pipeline alongside the Default one, enable it, edit it and switch between the two.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/lead-management
- Menu path: **Marketing > Lead Management**

## Steps
### Create
1. Go to **Marketing > Lead Management**, click **Create Sales Pipeline** (top right).
2. Enter a name and the number of stages (default stages: New Leads, Won, Abandoned; up to 20 allowed). Click **Save**.
3. For each stage, edit title/description and tick or untick the attributes shown on lead cards (all on by default; some are locked on; **Intro Offers** is off by default).
4. Click **Yes, Save**.

### Enable and manage (use the vertical ellipsis menu beside the pipeline name)
- **Edit Pipeline**: change stage names, descriptions, attributes; **Save** top right.
- **Enable Pipeline**: makes this the active pipeline for new leads.
- **Settings**: pipeline settings, Lead Distribution, set triggers.
- **Sales Funnel Analytics**: opens the report; filter by Default or Configurable pipeline (Enterprise has its own franchise-wide report).
- **Open Pipeline**: switch between Default and Configurable views.

## Gotchas
- Package-dependent. Needs the "Ability to manage Sales Pipeline and update lead channels list" permission.
- Only one Configurable pipeline allowed; the Create button disappears afterward.
- In an organization/franchise, only the organization can create it, in the template site first; franchisees cannot.
- Enabling it automatically disables the Default pipeline (only one active at a time). Default is active until you do this.
- Settings/Lead Distribution/Set Trigger are read-only while a pipeline is inactive.
- Existing Default-pipeline leads do not move over. Re-add manually per lead: mark client as prospect and change lead stage in the client profile.
- Once any lead is in the pipeline, stages cannot be added or removed unless those leads are deleted first. (Deleting leads is destructive; confirm with user.)
