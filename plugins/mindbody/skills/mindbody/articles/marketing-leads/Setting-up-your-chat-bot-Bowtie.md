# How to set up the chat bot (Messenger[ai])

Customize the Messenger[ai] webchat widget (branding and behavior) and get its embed code for your website so clients can book appointments from your site.

## Where in Mindbody
- Direct link: https://messenger.mindbodyonline.com/login/
- Menu path: Messenger[ai] > Settings gear (left) > **Webchat**.

## Steps
1. Log in to Messenger[ai], click the **Settings gear**, choose **Webchat**.
2. Set **Webchat Branding** (below).
3. Set **Widget Preferences** (below).
4. Use the copy-widget-code control at the top of the screen and paste the code into your website's footer (exact method depends on your web provider).

## Settings & fields
- **Chat Color**: widget banner color. Avoid light/white; text is light gray by default so boxes and buttons look blank.
- **Bot Avatar**: avatar shown in conversations.
- **Webchat Logo**: header logo; best transparent with white lettering.
- **Background Image**: faded header image; also reused as the header of Messenger confirmation emails.
- **Replace Booking Links**: redirects the site's "Book now" buttons to the widget.
- **Hide CTA On Close**: if a client closes the popup bubble, it stays hidden across pages and refreshes.
- **Delay Widget Load**: seconds to wait before loading.
- **Fade Widget Call-To-Action**: seconds before the bubble fades; 0 means never fade.

## Gotchas
- Package/add-on dependent. Only managers can retrieve the widget code.
- **Open Widget On Load** (auto-open on page load) can only be changed by contacting Customer Support.
- Embedding happens outside Mindbody; Support will not help with setup. Suggest passing the code to a web developer.
