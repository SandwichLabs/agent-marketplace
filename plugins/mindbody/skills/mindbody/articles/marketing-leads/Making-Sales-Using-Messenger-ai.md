# How to sell with Messenger[ai]

A five-step workflow for turning first-time visitors into buyers using Messenger[ai]: follow-up texts, checking the client profile, outreach, and in-chat checkout.

## Where in Mindbody
- Direct link: https://messenger.mindbodyonline.com/login
- Menu path: Messenger[ai] > Settings gear (left) > **Follow Up Texts**.

## Steps
1. **Enable follow-ups**: log in to Messenger[ai], click the Settings gear, choose **Follow Up Texts**, scroll down, and switch on **Send Class Follow Up Texts**. These texts go out shortly after a client's first visit and gather feedback and goals.
2. **Review replies**: regularly check the Follow-Ups section of the chat dashboard for recent responders.
3. **Check the client profile** for upcoming classes, appointments, and purchases to see if they are already returning.
4. **Reach out** to clients with nothing booked or bought: invite them back, optionally with an offer. Use Broadcast to message several at once and saved replies to save time (messages can include a {client_name} placeholder).
5. **Close the sale** in chat: click the shopping cart icon at the bottom of the chat, add a pricing option; the bot then takes over. The client replies "yes" and pays with the card on file (or is prompted to add one).

## Gotchas
- Some features depend on software package.
- Checkout charges the client's card; confirm the offer and price with the user first.
