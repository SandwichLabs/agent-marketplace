# Schedule a class screen

Explains the single-page workflow for putting a single class or a repeating series onto the schedule from an existing class service. Use it whenever an agent needs to add class sessions.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/servicesandpricing/Classes
- Menu path: **Services & Products > Classes**

## Steps
1. Open **Services & Products > Classes** and find the class service.
2. Click **+Schedule** beside it.
3. Fill in the four sections (Where and when, Class size, Online options, Pricing).
4. Click **Schedule Class** (bottom right). The sessions land on the Class Schedule screen and the Manage Schedules screen opens.

## Settings & fields
**Where and when**
- **Recurring class** / **Single class**: repeating series vs one date (starts and ends same day).
- **Start and End date**: typed or via calendar picker.
- **Location**: only shown for multi-location (datashare) businesses.
- **Days of the week**: the day matching the start date is pre-highlighted; click circles (Su, Mo...) to add/remove days.
- **From / To**: session times for every chosen weekday; end time auto-fills 45 or 60 minutes after start.
- **Repeats every / Frequency**: defaults to weekly; pick a different interval (e.g. 3 = every third week). Cannot be changed after the class is added.
- **Staff**: instructor; **Add New** in the dropdown opens a pop-up to create one.
- **Pay rate**: instructor pay for this class.
- **Room**: shown if rooms are used.
- **Layout**: only when Pick-a-Spot is on; choosing one fills Total capacity from its active spots.
- **Add another time**: extra sessions for the same class with different day/time/staff.

**Class size**
- **Total capacity**: max registrants. With Pick-a-Spot it auto-fills, and can be lowered but not raised past the layout's active spots.
- **How many people can waitlist?**: waitlist cap.

**Online options**
- **Allow clients to sign up for the class online**: unchecked means in-person registration only.
- **Online capacity**: online cap; set below total capacity to hold spots for walk-ins.

**Pricing**
- **Allow clients to sign up now and pay later**: online registration with payment taken in person. Unchecked means payment is required at online booking (clients without a pricing option can use account credit or a card).
- **Clients can attend this class for free**: makes the class no-charge.

## Gotchas
- Some features depend on the software package.
- Staff need the permissions **Manage class/event schedules** and **Manage classes/events descriptions** to use the scheduler.
- The repeat interval is locked after scheduling; fixing it means editing/deleting and re-adding.
- There is no minimum-attendance setting; low-booked sessions must be cancelled manually.
- Extra per-session settings live in the Edit Scheduled Class/Event screen.
