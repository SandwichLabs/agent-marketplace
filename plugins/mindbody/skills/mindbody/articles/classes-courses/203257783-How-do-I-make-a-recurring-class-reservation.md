# How to use Adv Register on the class schedule to make recurring reservations

Staff-side way to book a client into repeated sessions of a class (e.g. every Tuesday for a quarter) from the Class Sign In screen.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/classic/admmainclass?fl=true
- Menu path: **Classes > Sign In > Adv. Register**

## Steps
1. Click **Classes** in the left nav, then **Sign In** for the class.
2. Click **Adv. Register** (right side).
3. Search for and select the client.
4. Set recurring options: **Make this reservation every** (frequency), **Select days**, **Start date**, **End date**.
5. Click **Make a recurring reservation** to have the client pay now, or **Register as unpaid** to pay later.
6. Verify on the client's Schedule screen.

## Gotchas
- Button is hidden if the roster is full or the class is marked free.
- Maximum span is one year from today or the class end date, whichever is sooner.
- Online (consumer site) recurring bookings draw on one pricing option at a time; if it cannot cover all sessions the client is asked for extra payment.
- Affected by schedule windows, "Day of Month Scheduling Opens for Next Month", and very long class schedules (can cause loading problems).
- Multi-day recurrence (e.g. Mon/Wed/Fri) requires **Bundle classes to allow for multi-day recurring reservations** in Class and Course Options; bundling means staff, time or room cannot be changed per individual day.
- Registering via Adv. Register sends the Reservation Confirmation email (if enabled); the quick client search path does not.
