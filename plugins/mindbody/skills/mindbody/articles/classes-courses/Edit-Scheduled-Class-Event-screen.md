# Edit Scheduled Class/Event screen

Screen for changing behavior of an existing scheduled class or course: capacity, online booking, free/unpaid signups, visibility, room, waitlist, assistant pay. Use it to modify a class that already exists (not to create one).

## Where in Mindbody
- Class Schedule: https://clients.mindbodyonline.com/app/business/classic/admmainclass?fl=true (**Classes** in nav)
- Classes setup: https://clients.mindbodyonline.com/app/business/servicesandpricing/Classes (**Services & Products > Classes**)
- Course Schedule: https://clients.mindbodyonline.com/app/business/asp/adm/main_enroll.asp?fl=true (**Courses** in nav)
- Courses setup: https://clients.mindbodyonline.com/app/business/servicesandpricing/enrollments (**Services & Products > Courses**)
- Manage Schedules: https://clients.mindbodyonline.com/app/business/asp/adm/adm_cs.asp (**Settings > Classic Setup > Manage Schedules**)

## Steps
### Open the screen
1. From a schedule screen or Manage Schedules, click the class/course name (or the 3-dot icon under the Edit column on the class schedule).
2. From Services & Products, click **# schedule(s)** next to the class/course and choose the date range.
3. Change settings and click **Save**.

### Find the Class ID
1. Open the screen for the class, read the number after "classID=" in the browser URL.

## Settings & fields
- **Add New Class/Event**: jumps to Classes in Services & Products.
- **Edit this Class/Event Description**: goes to the Edit a Class screen (name, description, level).
- **Delete**: only when nobody is registered. A course with a removed client who still has an event balance needs that balance cleared first.
- **Show to Public**: visible in consumer mode.
- **Mask Teacher**: hides teacher name in consumer mode.
- **Assistant** and **Paid by teacher**: checked deducts assistant pay from the main teacher's rate; unchecked, the business pays.
- **What is the total capacity?**, **How many people can book online?** (cannot exceed total).
- **Waitlists**: capacities settable once waitlists are enabled in Class and Course Options.
- **Dates**: start/end.
- **Unpaid Online Signups**: clients can sign up online unpaid and settle on arrival.
- **Free Class**: books free.
- Lower section: **Use leader/follower split**, **Regularly assigned room** (assign/clear/check conflicts; Pick A Spot layout shown if enabled), **Delete class cancellations** (removes all future cancellations), **Make Schedule Change**, **Class Tests**, **Costumes** (these need their features enabled).

## Gotchas
- From Services & Products the add-new and edit-description links are missing.
- Class date cannot be edited if a room is assigned or clients are registered.
- Free Class does not work with Advance Course Management.
- With multiple schedules for one class, check the date columns to pick the right one.
- Branded web tools: hidden schedules are hidden in the booking widget; Mask Teacher affects only the Schedule widget (Enrollment widget has its own Instructor filter; Appointment widget cannot hide names). The Check-in app still shows hidden staff.
- Deleting a class and deleting future cancellations are hard to reverse; confirm with the user first.
