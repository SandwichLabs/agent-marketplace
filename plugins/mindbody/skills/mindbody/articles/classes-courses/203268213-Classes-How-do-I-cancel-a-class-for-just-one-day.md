# How to cancel a class for only one day

Two ways to cancel a single occurrence of a live stream, in-person or hybrid class without ending the whole schedule.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/classic/admmainclass?fl=true
- Menu path: **Classes** (left nav)

## Steps
### Option 1: from the Class Schedule (quick)
1. Click the three-dot menu to the right of the class on the right day.
2. Choose **Cancel or delete class**.
3. Select **Cancel this one class**, then pick **Hide** or **Show** the cancellation.

### Option 2: Make Schedule Change
1. Click the class name, then **Make Schedule Change** at the bottom.
2. In **Please select the type of change** choose **Class/Event cancellation**.
3. Click **Submit**. A red cancellation message replaces the class on the schedule.

## Gotchas
- ⚠️ Irreversible / financial — confirm with the user first: clients with reservations are cancelled (see Make Schedule Change article for undo limits).
- In branded web tools, cancelled classes never display, even when set to Show.
- Option 2 leaves red cancellation notes on the calendar; avoid it for many dates. To stop a class from a certain date on, change the class **End date** instead.
- Check the date selected before submitting; this should affect only that one day.
