# How to mass register multiple clients into a class or course

Register a whole group of tagged clients into a class or course in one click. Useful for teams, cohorts, or moving a roster from one class to another.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_ss_res.asp (Class and Course Options)
- Direct link: https://clients.mindbodyonline.com/app/business/classic/admmainclass?fl=true (Class Schedule)
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/main_enroll.asp?fl=true (Course Schedule)
- Menu path: **Settings > Services > Class and Course Options > Booking and Sign-in Policies**

## Steps
### Enable the feature (one time)
1. Open Class and Course Options, expand **Booking and Sign-in Policies**.
2. Under General Settings tick **Class Sign In - Enable Registering Tagged Clients**.
3. Click **Update**.

### Classes
1. Tag the clients (from a roster or report).
2. **Classes** > **Sign In** beside the class.
3. Click **Register Tagged Clients** (right of the client search box).

### Courses
1. Tag the clients.
2. **Courses** in left nav; for a single-day course click **Sign In Sheet**, for multi-day click **View Roster** then pick a date at top right.
3. Click **Register Tagged Clients**.
4. Repeat for each additional course date.

### Register a team
1. Create a client type named after the team (Client Types screen).
2. Assign it to each member (individually, or via Modify Tagged Clients for many at once).
3. Find them in the Client Directory by client type, click **Tag new**, then **OK**.
4. Use the class/course steps above.

## Gotchas
- Staff need the **Tag clients** permission.
- The number in parentheses on the button shows how many clients are tagged. If tagged clients exceed capacity the mass option is unavailable; raise capacity or add one by one.
- Register Tagged Clients does NOT send booking confirmation emails.
- Courses with a payment plan attached: remove the plan temporarily or enroll clients individually.
- Tag new replaces any previous tag list.
