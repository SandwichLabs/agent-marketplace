# How to change the time of one or some classes only

Method for a temporary time change on a recurring class without cancelling and re-adding it. The trick is splitting the series into three consecutive schedules (regular, temporary, regular again) using Make Schedule Change.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/classic/admmainclass?fl=true
- Menu path: **Classes** > click class name > **Make Schedule Change**

## Steps
1. Click **Classes** in the left nav, then click the class name (opens Edit Scheduled Class/Event).
2. Click **Make Schedule Change** (bottom right).
3. In **Please select the type of change**, choose **Permanent - From date forward**.
4. Enter the **start date** of the temporary change.
5. Tick **Time change**, set **New start time** and **New end time**.
6. Click **Submit**.
7. Click **Make Schedule Change** again, choose **Permanent - From date forward**, set the date the normal hours resume, and enter the ORIGINAL start/end times.
8. Click **Submit**.

## Gotchas
- Example outcome: a Thursday 9-10am class Jan 1-Dec 31 with an October change becomes three schedules (Jan-Sep 9-10, Oct 11-12, Nov-Dec 9-10); editing or removing one does not affect the others.
- For a class that is one day only, or to change only the first day, use **Permanent - All past and future** instead.
- Forgetting step 7 leaves the new time in force permanently.
- Needs the **Manage class/event schedules** staff permission and a package that includes the feature.
