# Class and Course Options screen: Class Schedule Appearance & Options

Reference for the settings that control how the class schedule looks and behaves for staff (business site) and clients (consumer site), including substitutions, recurring reservations, and Pick-a-Spot.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_ss_res.asp
- Menu path: **Settings > Services > Class and Course Options > Class Schedule Appearance & Options**

## Steps
1. Open Class and Course Options; use **Expand All** / **Collapse All** (top right) if helpful.
2. Open **Class Schedule Appearance & Options**, toggle settings.
3. Click **Update** to save.

## Settings & fields
- **Consumer Mode - Show Assistant** / **Show Assistant 2**: show assistant names on the consumer-site schedule.
- **Start Schedule on Monday or Sunday**: first day of week for business and consumer sites (the branded app always starts Sunday).
- **Open Weekly Classes Schedule to Current Day**: auto-scroll Classes screen to today.
- **Group Classes By Visit Type**: group by class type.
- **Business Mode Show Class Statistics**: shows signups and percent of capacity per day/week on the business schedule.
- **Consumer Mode Show # Open Class Spaces**: shows registered count and open spots (consumer site, Mindbody app, branded web tools).
- **Hide Sign Up buttons from clients without a current series**: consumer schedule shows Sign Up Now only for classes the client's pricing options can pay for.
- **Client Recurring Reservations**: lets clients book many sessions of a class at once; on by default.
- **Bundle classes to allow for multi-day recurring reservations**: bundles Mon/Wed/Fri style classes into one recurring reservation.
- **Show Service Category Menu**, **Show Class Type Menu**, **Show Class Level Menu** in Class Schedule: client-facing filters (level menu requires **Use Class Levels** on, appears on both sites).
- **Large/Multi-Loc Schedule use Daily List View**: one screen per day for big schedules.
- **Show Resources in Consumer Mode**: displays room/resource per class.
- **Show Substitute Teachers in Red** (consumer site), **Consumer Mode - Show Substitute Footnotes**, **Business Mode - Show Substitute Footnotes** (numbered footnote naming the usual instructor).
- **Enable Quick Teacher Substitution**: adds a per-class dropdown for swapping teacher; pay uses the substitute's default pay rate.
- **Enable Class Notes**: notepad icon per class for instructor reminders.
- **Default Date Set to Next Class**: schedule opens on the next date that has classes, on both sites.
- **Enable Automated Substitution Management**: automated texts to find substitute instructors.
- **Enable Pick A Spot**: turns on room layouts so clients pick a spot when booking.

## Gotchas
- Requires the **Class & Events Options Screen** staff permission under Settings.
- With Bundle enabled, staff, time and room cannot be changed for individual days within the bundle.
- To see red substitute names on the business site: enable Business Mode - Show Substitute Footnotes AND disable Enable Quick Teacher Substitution. Business footnotes also require Quick Teacher Substitution off.
- Enabling Pick A Spot only unlocks the feature; layouts and room assignments still need setup.
