# How to use Block Copy Class Schedules feature

Copies a week of existing class/course schedules onto a new date range so recurring offerings do not need to be rescheduled one by one. Handy when a season or course repeats on the same weekdays.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_cs_blockcopy.asp
- Menu path: **Settings > Classic Setup > Manage Schedules > Tasks (top right) > Block Copy Class Schedules**

## Steps
1. Open Manage Schedules, click **Tasks > Block Copy Class Schedules**.
2. Under copy FROM: set **Select Sunday of Week to Copy** (must be a Sunday), tick the **Select Days of Week to Copy**, highlight **Select Service categories to Copy**, optionally tick **Copy Assigned Pricing Options** (carries course pricing options over).
3. Under copy TO: set **New Start Date for Classes** and **New End Date for Classes**.
4. Click **Preview** to list what will be created.
5. Click **Execute** to save.
6. Fix any individual item afterward via its Edit Scheduled Class/Event screen.

## Gotchas
- Needs the **Block copy/cancel class and event schedules** staff permission.
- Works best when most classes are unchanged; one start/end date applies to all copied items (adjust individually afterward).
- NOT copied and must be redone on the new schedule: room assignments, payment plans, assistants, costumes, and date-forward/open course flags.
- Execute creates many schedules at once; review the Preview first.
