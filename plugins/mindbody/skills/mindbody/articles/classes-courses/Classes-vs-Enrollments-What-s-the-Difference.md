# Differences between classes and courses

Decision guide for whether an event should be set up as a class or a course (a.k.a. enrollment, workshop, event). Use before creating a new schedule item.

## Settings & fields
- **Class**: recurring, same time each week, 1-2 instructors, drop-in friendly, low commitment (drop-in, packs, unlimited). Clients pick which dates to attend.
- **Course**: fixed start/end dates, one registration covers the whole series, one instructor, typically pricier.

When to choose which:
- Sign up once for all dates: course only.
- Clients may take all dates or pick dates: course, with date-forward and/or open enrollment options enabled.
- Single one-day event: either.
- Same day/time weekly for three weeks: either.
- Different days/times for three weeks: course only, set up as an advance course.
- Listed in the Mindbody app, single date: either; multiple dates: class only.
- Installments or payment plan: course only.
- Pricing option limited to one specific schedule rather than the whole service category: course (alternative: put the class in its own service category).

## Gotchas
- Depends on software package.
- Class pricing options pay for every class in that service category; course pricing options pay only for specific events. Different prices for different dates means use courses.
