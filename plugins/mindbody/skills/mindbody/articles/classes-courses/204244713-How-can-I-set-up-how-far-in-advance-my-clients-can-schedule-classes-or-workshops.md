# How to set up schedule windows for classes and courses

Limits when clients can start and stop booking classes and courses online (how far ahead, and how close to start time). Applies to consumer site, branded web tools, Mindbody app, and branded apps. Appointments have their own article.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_ss_setup.asp (General Setup & Options)
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_ss_res.asp (Class and Course Options)
- Menu path: **Settings > General > General Setup and Options > Consumer Mode Settings**; **Settings > Services > Class and Course Options > Booking & Sign-in Policies**

## Steps
### 1. Scheduling hours (optional; default window opens 12:00 AM)
1. Open General Setup and Options, expand **Consumer Mode Settings**.
2. Set **Scheduling Hours** to **Custom**.
3. Choose **Scheduling Start Time** and **Scheduling End Time**.
4. Click **Update** (top right).

### 2. Window type and per-category limits
1. Open Class and Course Options, expand **Booking & Sign-in Policies**.
2. Set **Schedule Window Type**: Rolling, Monthly, or Weekly.
3. Set **Schedule Release Time**.
4. In **Schedule Windows**, set per service category row: **Starts** and **Closes**.
5. Click **Update**.

## Settings & fields
- **Type**: each service category; the window applies to everything in it.
- **Starts**: days ahead clients may book. 0 = as far as the schedule allows. Example: 7 = one week ahead.
- **Closes**: minutes before start that booking stops. 0 = until the last minute. Example: 30 means a 1:30 PM class must be booked by 1:00 PM.

## Gotchas
- Windows are per service category, not per class.
- Older branded app versions may still show sign-up buttons outside the window and error on attempt; newer ones say the class can't be booked online.
- Pair with cancellation windows if you also need notice for cancellations.
- Appointments use a different setup (see related).
- The Schedule Windows table is shown for the Rolling type; full type behavior is in the Booking & Sign-in Policies article.
