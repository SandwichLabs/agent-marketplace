# How to set up and schedule courses

Overview of the four-stage process for creating a course (also called an enrollment, workshop, or event): a multi-session offering where clients commit to all or most sessions. Use it as the roadmap before diving into the detailed screens.

## Steps
1. Create a course **service category** (required before adding a course).
2. Add the new course to a course category (Add New Enrollment screen).
3. Schedule the course sessions and staff (Schedule Enrollment screen).
4. Add or assign pricing. This is only possible AFTER the course is scheduled: find the scheduled course, then either add a new pricing option or assign an existing one.

## Settings & fields
Optional course features:
- **Payment plans** for courses.
- **Advance courses**: bundle several courses meeting at different times/days (or with different titles) so they are booked together. A course can belong to only one advance course at a time.
- **Semesters**: classify courses with preset date ranges.
- **Costume tracking**: assign a costume to a course.
- **Open course / date-forward course**: open courses override schedule window settings.

## Gotchas
- Essential software package cannot add course pricing options to contracts.
- Only single-day courses show in the Mindbody app.
- A newly added first-ever service may not show in apps until the next day.
- Removing an instance from a course does NOT remove existing registrations.
- For future-start courses, make the pricing option duration cover the time from purchase to the last session (e.g. one month early purchase = 30 days plus course length), or set it to activate on first visit.
- To stop clients buying course pricing options without enrolling, disable "Allow clients to purchase course pricing options without enrolling" in Class and Course Options (when on, they can buy online without registering, even if the option is not assigned to a course).
- Staggered/every-other-week courses need the blackout-days method rather than an advance course.
- Block Copy Class Schedules can extend a course schedule.
- Client View Settings (Tab Management) decide which consumer-site screen shows courses.
