# Class Schedule screen overview

Guide to the business-side Class Schedule screen: navigating dates, filtering, opening class sign-in, editing classes, and reading attendance totals. The main starting point for daily class operations.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/appshell/shuttle/classic/admmainclass?fl=true
- Menu path: **Classes** in the left navigation panel

## Screen elements
- **Calendar icon**: opens the month calendar; arrows change month, click a day to jump.
- **Today / Day / Week / Month** buttons: Today returns to the current day; the others step back/forward by a day, week, or month. Month cannot be the default view.
- **Filter menus** (top right): location, view, service category, class type, instructor. Inactive service categories are hidden. The Instructor list only has instructors with current or future scheduled classes (even when viewing a past date), and filtering by instructor excludes classes where they are only an assistant. Class type filter: one type or All in Today/Day/Week views; multiple types selectable in Month view.
- **More menu**: create/schedule a class, schedule a closed business day (holiday), set up auto notifications, go to Class and course Options, view hidden class cancellations.
- **Sign In link** per class: opens the Class Sign In screen to register clients and see who is booked, with alerts and payment details. Shows counts like 7/15 (registered/capacity) before the class, then signed-in count after. Colors: blue = future class; red = over capacity; gray = past class. Toggle via the "Business Mode Show Class Statistics" setting on Class and course Options.
- **Gear icon** per class row: edit class setup, cancel or delete the class, change instructor, add a class theme, change room, view client sign-up restrictions; possibly assign assistants or rooms.
- **Totals at bottom**: classes scheduled in the day/week, attendance (registered, signed-in, unpaids, capacity allowed), and capacity utilization % (signed-in / allowed capacity). Registered excludes late cancels. To find unpaid clients use the Schedule at a Glance report (red dot = unpaid) or Attendance with Revenue report (listed as "unpaid").

## Tips
- To print the month: click **Month**, right-click, choose **Print**, adjust layout/scale in advanced print settings. Alternatively sync staff schedules through the Google Calendar integration, choose Month, gear icon, **Print**.

## Consumer-site view
- Logging out and clicking **Classes** on the consumer site shows what clients see. Clients click **Sign Up Now**; if not logged in they are prompted to sign in or create an account. When class and waitlist are full online, they get a "full" screen.

## Gotchas
- Features vary by software package.
- Cancelling or deleting a class from the gear menu affects booked clients; confirm with the user first.
