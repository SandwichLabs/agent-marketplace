# How to set up, schedule, and create pricing options (livestream)

How to turn a service category into livestream (virtual) classes, schedule them, price them, and get links to clients. Livestream works for classes only (not courses or appointments).

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/servicesandpricing/Classes
- Direct link: https://clients.mindbodyonline.com/app/business/classic/admmainclass (Class Schedule)
- Menu path: **Services & Products > Classes**; **Classes > Sign In**

## Steps
### Set up livestream classes
1. **Services & Products > Classes**, create a new service category (recommended: one dedicated to virtual classes).
2. Create and schedule the classes. Set capacity (livestream max 250; only 15 participant videos display). Add registration notes saying the link arrives 30 minutes before class.
3. Add pricing: create a pricing relationship so other categories' pricing options can pay, or create new pricing in the virtual category.
4. In Services & Products, on the virtual category toggle **Live stream** to **On**.
5. For classes scheduled the same day you enable it, create the link manually (below). Future classes get links automatically.

### Create a link for a same-day class (at least 30 min before start)
1. **Classes > Sign In** on the virtual class.
2. Click **Create live stream link** (top right). After the link is sent, the button becomes **Live Stream Link**, which copies the link to the clipboard for manual sending.

## Gotchas
- ALL classes in a service category become livestream classes once the toggle is on; isolate virtual classes in their own category.
- Auto link email goes to booked clients and the instructor 30 min before class; late bookers get it 2-3 minutes after booking. Anyone booked after class starts needs the link sent manually (copy via **Live Stream Link**).
- Links for later days are created around midnight each night.
- The email is operational and overrides opt-outs. To log it as a contact log, disable "Require Contact Log Type" in General Setup & Options; filter contact logs by "Non-system generated email notifications". Sent from a no-reply address; replies go to the reply address in Locations and Mindbody App Listings.
- Needs the livestream add-on to host via Mindbody; without it, stream elsewhere and still book/pay through Mindbody.
- Permissions: View Services & Pricing and Service Categories screen (Settings) to toggle; View reservations, Make reservations, Make past reservations to start a stream or create links. Essential subscribers: only owner login can access Services & Products.
- Recommended: Mindbody Live desktop app, or Chrome on desktop; Safari (iOS) / Chrome (Android) on mobile.
- Link only works for clients booked in the class; they log in to the site to join.
- Sales tax on virtual products: consult a tax expert.
- Licensed music/video: consult a legal adviser.
- Reporting via the Live Stream Classes report.
