# Class and Course Options screen: Directory

Index of the Class and Course Options settings screen, which governs booking rules, sign-in behavior, schedule appearance, and course features. Use it to locate where a given setting lives, then follow the linked detail article.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/asp/adm/adm_tlbx_ss_res.asp
- Menu path: **Settings > Services > Class and Course Options**
- Also: Class Schedule screen > **More > Class and Course Options**

## Steps
1. Open the screen via the path above.
2. **Expand All** / **Collapse All** (top right) toggles sections; browser find (Ctrl/Cmd+F) locates a setting name and opens its section.
3. Change settings, then click **Update** to save.

## Settings & fields
The screen has three sections; each is documented in its own article.
- **Booking & Sign-in Policies**: unpaid scheduling restrictions, schedule window type (Rolling/Monthly/Weekly), schedule and cancellation windows, default schedule lengths, waitlist options, duplicate/overlap bookings, class levels/testing/leaders-followers, auto sign-in, sign-in/late check-in windows, no-show pay and deduction, prerequisites, sign-in sheet and self sign-in display options, assistants 1 and 2, visit milestones.
- **Class Schedule Appearance & Options**: assistant visibility, week start day, grouping, statistics, open spaces, sign-up button hiding, recurring reservations and bundles, filter menus, daily list view, resources, substitute display and Quick Teacher Substitution, class notes, default-to-next-class date, Automated Substitution Management, Pick A Spot.
- **Course Schedule Appearance & Options**: assistants, auto load selected client, semesters, advance courses, default view/sort, course descriptions, already-started courses, open courses, filter menus, reservation notes, hiding times, make-up tracking (cross-class, max per course), registrations on client info, resources, buying course pricing options without enrolling, drop-in-specific capacities and drop-ins increasing capacity.

## Gotchas
- Needs the **Class & Events Options Screen** permission (Settings) to edit.
- Some options depend on the software package.
- This page is only an index; setting details are in the three child articles.
