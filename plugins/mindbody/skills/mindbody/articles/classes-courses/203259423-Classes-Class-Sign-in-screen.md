# Class Sign In screen

The class roster screen: see who is registered, sign clients in, register walk-ins, swap pay methods, substitute a teacher, launch a livestream, or jump to Point of Sale. Needed for any front-desk or attendance task on a specific class.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/classic/admmainclass?fl=true (Class Schedule)
- Menu path: **Classes** (left nav) > **Sign In** next to the class

## Steps
1. Click **Classes** in the left nav.
2. Click **Sign In** beside the class to open its roster.
3. Use the controls below to register, sign in, cancel, or substitute.

## Settings & fields
**Header and navigation**
- **Assistant** dropdown: change assistant(s) for this session only.
- **More > Print this page**: printable roster. **Sign In Sheet** opens a printable sheet; **Attendance report** opens Attendance with Revenue.
- **Previous/Next Occurrence of This Class** and **Previous/Next Class on Schedule**: move between sessions.
- **Quick Cash Products**: if enabled, clicking + marks a low-cost cash-only product sold (appears as a Walk-In cash sale on the Sales report).
- Count tiles: **Teacher paid for**, **No-Shows** (not signed in), **Signed in**, **Total Count** (excludes late cancels), **Capacity**.

**Adding clients**
- **Search for client**: find or add a new client and register them. This quick path does NOT send the Reservation Confirmed auto email.
- **Adv. Register**: recurring reservation; does send the Reservation Confirmation email (if enabled and client opted in).
- **Register Tagged Clients**: appears only if "Class Sign In - Enable Registering Tagged Clients" is on; mass-registers tagged clients.
- **Tag add (green)** appends the roster to the tag list; **Tag new (yellow)** replaces the list.
- **Alert clients who did not pre-register**: checkbox shown if "Non Preregistered Client Alert" option is on; staff then see a "NOT Pre-Registered!" alert.

**Teacher changes**
- **w/** checkbox + instructor menu: substitute for this one date only, using the new teacher's default pay rate.
- **Substitute**: opens Make Schedule Change for date ranges and pay rate changes.

**Livestream**
- **Live Stream Link**: copies the class link to email to clients manually.
- **Start live stream**: needs the livestream add-on and a livestream-enabled class. Start 10-15 min early; attendees are signed in automatically on joining; closing the browser tab ends the stream.

**Roster columns / icons**
- Visit milestone icons (green star / cup) if Visit Milestones enabled.
- Red liability waiver icon: click to email the client a signature request.
- **Sort by**: Sign-In order, Last name, First name.
- **ID** (needs "Show Client IDs" option), **Balance** (needs "Show Account Balances"; red = negative, green = positive; separate option gives a pop-up alert for negative balances).
- **Email** / **Phone #** (grayed phone icon = client opted out of waitlist SMS; they can text START to rejoin).
- **Leaders/Followers** column (if feature enabled; toggle per client). **Rank** column (Progress Tracking). **Spot** column (Pick-a-Spot; dropdown assigns spot and emails confirmation by default if client has email). Belt visits/promotion date columns for martial arts belts.
- **Payment Type**: "Unpaid [Service category]" or the pricing option name. **Change** link: swap to another active pricing option (works even if the option isn't set for that service). **Expiration Date**, **Remaining** (future-booked sessions are not counted as used; for unpaid bookings it shows unpaid past reservations in the category).
- **(Expires in # day)** red alert: unlimited pass expiring within a week; not shown for limited options or membership-attached options.
- **Web** checkbox: booked online.
- **Signed In** checkbox: manual sign-in. **Late Cancel** checkbox: manual late cancel (auto-checked when client late-cancels online).
- **Waitlist Notified / Waitlist Confirmed** checkbox: for clients added from the waitlist (named Confirmed if no SMS). Marking it confirms manually. Members can be given priority waitlisting.
- **Payment Status** (waitlist): Free Class; Pending: [pricing option]; Pending: Unpaid [category] (red, e.g. membership/autopay); Invalid: No active payment type or limited by scheduling restriction (red; client is not auto-added and gets a text unless opted out).
- **X icon** (red): early cancel, removes client and returns the session to their pass.
- **Buy**: opens Point of Sale to sell a pricing option that covers the visit. **Account**: client Account Details.

## Gotchas
- Staff permissions: View reservations (open screen), Make reservations (register/sign in), Make Past Reservations, Override Cancel Policy (early cancel after class start), Edit client's series (duration/reassign payment, for **Change**), Ability to view all clients (search). Multi-location sites also need the Marketing permission to switch locations while logged in.
- Auto sign-in: needs "Automatically Sign In Future Reservations" in Class and course Options. Staff registrations made after class start are auto signed in. Livestream joiners are always auto signed in.
- Many columns/alerts depend on toggles in the Class and course Options screen.
- Missing Adv. Register button has its own troubleshooting article.
- Early cancel via X after class start requires Override Cancel Policy.
