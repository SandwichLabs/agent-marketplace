# How to end, cancel, delete, remove, or hide classes

Covers the ways to take scheduled classes off the schedule: ending a series by end date, cancelling single/blocks/all-following sessions, deleting, and controlling whether cancellations are visible to clients. Applies to classes only (courses have their own article).

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/classic/admmainclass?fl=true
- Menu path: **Classes** (left nav)

## Steps
### End a class series (preferred when a class is discontinued)
1. Open **Classes**; make sure no clients are booked past the intended last date (early cancel them and notify them if so).
2. Click the class name to open it.
3. If rooms/resources are used, clear the room.
4. Set **End date** to the last day it will run.
5. Click **Save**. Removes the class after that date without touching history and frees rooms/resources.

### Cancel / delete from the schedule
1. Click the three-dot menu beside the class > **Cancel or delete class**.
2. Pick one:
   - **Cancel this one class**: one session; if clients are enrolled you can view roster, tag them, generate the Class/Event Cancellation Auto Email, and email the instructor.
   - **Cancel a block of classes**: choose date range and weekdays; can email instructor after review.
   - **Cancel all following**: everything from a chosen date onward.
   - **Permanently remove class**: only available if nobody has ever enrolled.
3. On the next screen choose whether the cancellation is visible or hidden to clients (hide later via the gear icon beside the cancelled class).
4. Complete the cancellation.

### Delete from Edit Scheduled Class/Event
1. Click the class name on Classes to open Edit Scheduled Class/Event.
2. Click **Delete** (top right), then **OK** to confirm.

## Gotchas
- ⚠️ Irreversible / financial — confirm with the user first. Permanent removal/Delete cannot be undone; cancelling classes with enrolled clients affects their bookings and sends notifications.
- Staff need **Manage class/event schedules** and **Manage classes/events descriptions** permissions.
- End date change is blocked by: future teacher changes/substitutions after the new end date, future scheduled cancellations after it, or a room/resource still assigned. Delete those first / clear the room.
- Delete and Permanently remove are unavailable (grayed out) once any client has signed up for any occurrence; cancel all bookings first or use cancel options.
- Courses are cancelled differently; replacing a class within the same service category uses Make Schedule Change.
