# Editing classes overview

Decision guide for which screen to use when modifying an existing class: schedule shortcuts, the Edit a Class screen (categorization), Edit Scheduled Class/Event (features), or Make Schedule Change (time/teacher/room over a date range).

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/classic/admmainclass?fl=true
- Menu path: **Classes** (left nav), then the three-dot menu beside a class

## Steps
### Quick teacher substitution
1. On **Classes**, tick the checkbox in the Teacher column.
2. Choose the substitute from the dropdown (applies to that one class on that day only).

### Three-dot edit menu options
- **Edit class setup**: Edit Scheduled Class/Event screen.
- **Cancel or delete class**: cancellation lightbox.
- **Change instructor**: Make Schedule Change screen.
- **Assign a room**: Edit Scheduled Class/Event.
- **Add class theme**: attach a theme to the scheduled class.
- **View client sign-up restrictions**: view/edit restrictions (e.g. membership-purchase limits).

## Settings & fields
Which screen edits what:
- **Edit a Class** (from Services & Products; categorization/info): class name, category, type, level, image, description, prerequisite notes, prerequisite client types, auto-assigned client types, age prerequisite, notes, registration notes.
- **Edit Scheduled Class/Event** (functionality): Delete, Show to Public, Mask Teacher, Total capacity, Online booking capacity, Wait Lists, Unpaid Online Signups, Date, Free Class, leader/follower split, Regularly assigned room, Delete class cancellations, Make Schedule Change, Class tests, Costumes.
- **Make Schedule Change** (permanent or temporary over a date range): Teacher, Assistant, Class or workshop, Time, Room, Layout.

## Gotchas
- Multi-day schedules (e.g. M/W/F) are saved as separate schedules per day in Manage Schedules, so each day can be edited individually, unless the block was bundled for multi-day recurring reservations; then staff, time, room cannot be changed per day.
- To drop a single weekday from a multi-day class, end the class and rebook it.
- Staff permissions for class editing are listed in a separate article.
- This article is about existing classes; new class setup is a different article.
