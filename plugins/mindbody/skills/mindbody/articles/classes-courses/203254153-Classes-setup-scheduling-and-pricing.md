# How to set up your class services (add, schedule, and price)

End-to-end setup of a class (multi-student service with no long-term commitment): add the class, schedule it, then attach pricing. Includes service category behavior.

## Where in Mindbody
- Direct link: https://clients.mindbodyonline.com/app/business/servicesandpricing/Classes
- Pricing step link given: https://clients.mindbodyonline.com/appshell/shuttle/servicesandpricing/Classes
- Menu path: **Services & Products** > **Classes**

## Steps
### 1. Add a class
1. On Classes, click **+Add Class** beside the target service category (create the category first if needed).
2. Fill the Add a Class form, click **Add**.
3. The class appears with options to add another, **+Schedule**, or **Add Pricing**.

### 2. Schedule it
1. Click **+Schedule** next to the class name.
2. Fill in sections (dates, times, staff, etc.), click **Schedule Class** (bottom right). You return to Manage Schedules.

### 3. Add pricing
1. Click **Add Pricing** and choose **Single session**, **Multiple sessions**, **Unlimited sessions**, **Autopay/Contract**, or **Manage pricing relationships**.
2. On the Add a Pricing Option screen enter name, price, extra settings; click **Add**.

## Settings & fields
Add a Class
- **Class name** (shown on schedule; include style/level), **Class category and subcategory** (help discovery online), **Class Type** (pick or **Add New**; refines a service category, e.g. Reformer vs Tower), **Image**, **Description**, **Additional options**.
Additional options
- **Prerequisite notes** (informational only; shown to clients only when a prerequisite client type exists), **Prerequisite client types** (enforced; clients need one, or all if "Require All Prerequisite Client Types" is on in Class and course Options), **Auto-assigned client types** (given to attendees), **Age prerequisite**, **Notes** (shown on consumer schedule), **Registration notes (used in confirmation notifications)** (appear only if <REGNOTES> replace phrase is placed in the notification body).
Service category gear menu
- **Allow online scheduling** (globe icon when on), **Rename service category**, **Show inactive classes**, **Show inactive pricing options**, **Manage pricing relationships** (e.g. Kickboxing pricing also pays for Weight Training), **Deactivate service category**, **Allow live stream** (does not put classes in the Mindbody app).

## Gotchas
- All classes in one service category are payable by the same pricing options. A class with unique pricing should get its own service category, otherwise the cheaper option can pay for the pricier class and existing passes in that category cover it.
- Different prices (e.g. $10 yoga vs $15 cycling) mean separate categories.
- Courses/enrollments (attend every session) are set up differently.
- Deactivated classes, pricing options, and categories are retained for reporting and can be reactivated.
- Some features depend on software package.
