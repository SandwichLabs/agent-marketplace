# Schedule or change classes

Add a class to the schedule, change the time or teacher of one or several sessions, substitute a teacher for one class, or add a closed business day. Typical phrasings: "add a Saturday 9am yoga", "move Thursday spin to 6:30 for October", "Jess is out, sub Alex into tomorrow's 7am", "we're closed July 4".

## Ask the person for
- Class name (it must already exist as a class service; see Variations if not), days, start and end times, date range, instructor, room, capacity.
- For changes: which class, which dates, new time/teacher, and whether it is temporary or permanent.
- For substitutions: the single date and the substitute.
- For closed days: dates, name (max 40 characters), all categories or only some.

## Steps
### A. Add a class
1. **Open Classes setup** — navigate to https://clients.mindbodyonline.com/app/business/servicesandpricing/Classes (**Services & Products > Classes**). Find the class service and click **+Schedule**.
2. **Where and when** — choose **Recurring class** or **Single class**; enter **Start and End date**; click the weekday circles; set **From / To**; choose **Staff**, **Pay rate**, **Room** (if shown). Use **Add another time** for extra days/times. The **Repeats every** interval cannot be changed later, so confirm it.
3. **Class size and online** — set **Total capacity**, waitlist limit, **Allow clients to sign up for the class online**, **Online capacity**, and the pay-later/free options as the person specified. Do not guess; leave defaults if not stated.
4. Summarize the settings to the person, then click **Schedule Class**. The Manage Schedules screen opens.

### B. Change time or teacher (one or some sessions)
1. Navigate to https://clients.mindbodyonline.com/app/business/classic/admmainclass?fl=true (**Classes**), click the class name, then **Make Schedule Change** (bottom right).
2. Temporary time change: use the three-schedule method. Choose **Permanent - From date forward**, enter the start date, tick **Time change**, enter new start/end, **Submit**. Then **Make Schedule Change** again, **Permanent - From date forward**, the date normal hours resume, the ORIGINAL times, **Submit**. Skipping the second pass makes the new time permanent.
3. Teacher change: pick the type (**Temporary - Date range** for an absence; **Permanent - From date forward** for a new teacher), tick **Teacher change**, choose the teacher and pay rate. Avoid **Permanent - All past & future** unless correcting a setup mistake; it rewrites payroll history, so ask first.

### C. Substitute one class
1. First time only: **Classes > More > Class and course Options**, expand **Class Schedule Appearance & Options**, tick **Enable Quick Teacher Substitution**, **Update**.
2. On **Classes**, find the class on the right day, tick the checkbox in the **Instructor** column, and choose the substitute. This covers only that date and pays the substitute's default rate.

### D. Closed business day
1. Navigate to https://clients.mindbodyonline.com/app/settings/closed-days. Run the Schedule at a Glance report first to see existing bookings; cancelling those is a separate 🔴 task.
2. Enter **Start Date**, **End Date**, **Name of closed day / holiday**. For a partial closure open **Service Categories** and tick only those to close.
3. Click **Add closed day**.

## Verify
- Classes: open the day or week view and confirm time, teacher and room (screenshot). Check the original schedule resumed after a temporary change.
- Closed day: appears in the Scheduled Closed Days list.

## If it goes wrong
- Time change drops the assigned room; reassign it on Edit Scheduled Class/Event.
- Missing options: the person needs **Manage class/event schedules**; features vary by package.
- Closed days do not cancel bookings or notify clients; tell the person if bookings exist.
- Class not showing: see [why classes don't show](../../articles/classes-courses/203268893-Classes-Why-aren-t-my-classes-showing-on-my-schedule.md).
