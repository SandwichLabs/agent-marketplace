# Claude in Chrome playbooks for Mindbody

Step-by-step playbooks for core studio workflows, written for an agent driving the Mindbody business site through the Claude in Chrome extension. Read [the general guide](../README.md) first (tool loading, navigation order, dialogs, safety levels). Each playbook says what to ask the person for, which reference pages to read, the exact steps, where to stop for confirmation, and how to verify.
