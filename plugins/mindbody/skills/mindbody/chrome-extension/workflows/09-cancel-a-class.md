# Cancel a class

Cancel one class occurrence, a block of dates, or end a recurring class, when clients may already be booked. Typical phrasings: "cancel tomorrow's 6pm spin", "we're not running Saturday classes this month", "end the Tuesday yoga class after June 30".

## Ask the person for
- Which class, which date(s), and the reason.
- Whether clients should see the cancellation (**Show**) or not (**Hide**).
- Whether to email booked clients (Mindbody does not do this for every path; see below).
- For ending a series: the last date it should run.

## Steps
1. **Open the schedule** — navigate to https://clients.mindbodyonline.com/app/business/classic/admmainclass?fl=true (**Classes**). Navigate to the right day and find the class.
2. **Check the roster** — click **Sign In** beside the class and get_page_text to list who is booked and the count (for example 7/15). Note unpaid or pass-based clients. Close without changing anything.
3. **Choose the scope** — one session: **Cancel this one class**. Several dates: **Cancel a block of classes** (date range and weekdays). From a date onward: **Cancel all following**. Class discontinued: prefer ending the series (step 7).
4. 🔴 Stop: show the class, date(s), number of clients booked (names if few), whether the cancellation will be Shown or Hidden, and whether the cancellation email will go out. Explain that booked clients are early-cancelled and cancelled reservations are not automatically restored if the class is later un-cancelled. Wait for an explicit yes for this cancellation.
5. **Cancel** — click the three-dot menu (gear) beside the class > **Cancel or delete class**, pick the option from step 3. If clients are enrolled you can view the roster, tag them, generate the Class/Event Cancellation Auto Email, and email the instructor; do this only as the person asked. A native confirm box may appear; warn the person beforehand and, if the browser stalls, ask them to click OK.
6. **Show or hide** — choose whether clients see the cancellation, then complete it. (Alternative for one day: click the class name > **Make Schedule Change** > **Class/Event cancellation** > **Submit**; it leaves a red note on the calendar.)
7. **End a series instead** — click the class name; if rooms are used clear the room first; set **End date** to the last day; **Save**. First early cancel clients booked past that date (🔴, same stop as step 4).

## Verify
- The class row shows a red cancellation message (or is hidden if you chose Hide). Re-open **Sign In** to confirm clients are no longer on the roster.
- For an ended series, future dates show no class.

## If it goes wrong
- Delete or Permanently remove is grayed out once anyone has ever signed up; use a cancel option. Never use Delete here without a separate explicit yes.
- End date will not change: a future substitution, scheduled cancellation or assigned room blocks it; clear those first.
- Clients are not notified automatically by the schedule change; the cancellation email goes only to the assigned instructor, not substitutes. Offer tagging clients and a mailing list for notification.
- Cancelled in error: the docs say a class cancellation can be undone, but clients' reservations must be restored manually via the Cancellations report ([undo article](https://support.mindbodyonline.com/s/article/203267723-Classes-How-do-I-undo-a-class-cancellation?language=en_US)).
- Missing option: needs **Manage class/event schedules**.
