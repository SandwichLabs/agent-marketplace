# pr-sizzle-reel

Plan a short, beat-matched Instagram reel for **The PR Method Fitness** from your own class footage, set to a song from
your own music library, then build it in CapCut with step-by-step help.

Claude asks four questions (what it's for, how long, which song, which clips), pins down the song's tempo and drop,
writes the on-screen lines in the studio's voice from its brand sheet, times every cut and line of text to the beat, and
walks you through CapCut one section at a time. The first PR Method reel, and how it was made:
[sandwichlabs.dev/for/prmethod/sizzlereels](https://sandwichlabs.dev/for/prmethod/sizzlereels/).

**Install:** see the [marketplace README](../../README.md#install). On Claude desktop, paste the prompt and Claude follows
[SETUP.md](SETUP.md).

## What's inside

| File | What it's for |
| --- | --- |
| `SKILL.md` | The steps Claude follows, from the four questions to the final check before you post. |
| `brand.md` | Colours, fonts, the lines from the website and walls, the classes and the offer. Claude only uses claims from this sheet. |
| `music.md` | Picking a track from your library, finding its drop and tempo, and checking you can use it on Instagram. |
| `examples.md` | The first reel, bar by bar: what was on screen, which clip, which effect. The model for the next ones. |
| `capcut.md` | A CapCut walkthrough: beat markers, text, the drop, export, and a checklist. |

A new offer or class? Update `brand.md` and bump `version` in `plugin.json`.
