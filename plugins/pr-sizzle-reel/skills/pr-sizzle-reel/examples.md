# Worked example: the first PR Method reel ("One more rep, y'all")

Use this as the model for structure, pacing and copy. It's 61 s, set to a French-house track at about 128 BPM, cut
from 27 shots of two of the studio's own Instagram reels. You can see it at sandwichlabs.dev/for/prmethod/sizzlereels.

| Bars | Part | On screen (exact words) | Footage | Effect |
|---|---|---|---|---|
| 1–2 | Hook | MOST GYMS / CHASE / INTENSITY. (on screen from frame 0), then an orange strike-through, line by line | squat, half speed (60 fps clip) | none: the words are the hook |
| 2–3 | Hook | WE FOCUS ON / QUALITY. / Movement · biomechanics · programming. | member portraits, half speed | letters pop in |
| 3–13 | Build | MOVE / WELL. · GET / STRONG. · PAIN- / FREE. · BUILD / STRONG. · EVERY REP / WITH INTENTION. · DONE / RIGHT. · EVERY / SESSION. (two words per sung phrase, the second in orange) | a cut on every beat across the class | small zoom pulse on each kick |
| 13–15 | Breather | NO EGO. / NO PRESSURE. (thin type) | stretching, child's pose, slowed | none |
| 15–19 | Build | Just training that helps you / LIVE / BETTER. · SMALL CLASSES. / PERSONALIZED CUES. / FORM COACHING. / EVERY SINGLE SESSION. with an orange bar filling toward the drop | cuts every 2 beats, then 1, then ½ | slight shake building |
| 21 | The lift | ONE / MORE / REP, / Y'ALL! (one word per beat, stacked) | a member swinging in front of the ONE REP AT A TIME wall, nearly frozen; the frame shrinks into a card | grey, quiet |
| 22 | **The drop** | (no text for one bar) | the most powerful clip: a trap-bar deadlift, low angle | one white flash, camera shake, the words shatter |
| 23–26 | Proof | REAL, LASTING / STRENGTH. · PAIN-FREE. / CAPABLE. / CONFIDENT. / AT ANY AGE. | a cut on every beat | a small extra hit on the crowd's "HEY!" |
| 26–27 | Proof | TEMPO STRENGTH · CORE + GLUTE + HIP · FUNCTIONAL FLOW · NEUBIE®-POWERED (2 beats each) | a cut on every beat | none |
| 27–28 | Proof | ONE REP / AT A TIME. (the studio's own wall) | the ONE REP AT A TIME wall | none |
| 28–32 | Offer | the neon logo, TRY A FREE WEEK., UNLIMITED CLASSES, THEPRMETHODFITNESS.COM, then CHICAGO / 7004 N CLARK STREET | the whole class, slowed | the logo flickers on |

What made it work:

- The hook is readable with the sound off, on the very first frame.
- One idea per beat, never more than five words on screen at once.
- The studio's own wall ("ONE REP AT A TIME") did more than any graphic could.
- A full bar of silence on screen right after the drop gave the hit room.
