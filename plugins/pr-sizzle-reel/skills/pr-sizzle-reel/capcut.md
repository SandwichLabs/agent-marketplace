# Building it in CapCut (desktop)

Give Phil one section at a time. CapCut moves its buttons between versions: describe what a control does, and if he
can't find it, ask what he sees and help from there. Don't guess at menu names you aren't sure of.

## 1. Set up the project

1. Open CapCut → **New project**.
2. Set the canvas to **9:16** (the ratio control under the preview player).
3. **Import** the song and the clips (drag them into the media panel).

## 2. Music and beat markers

1. Drag the song from his library onto the timeline first.
2. Trim it to the in and out points from the song map (`music.md`), so the reel starts at 0:00 on the in point. The drop
   must land at the exact moment the cut sheet says (for example "0:15.5, bar 8" in a 30 s reel).
   - If it's a commercial song that will be added in Instagram instead (see `music.md` → Rights), still use it here to
     time the edit, then **mute or delete it before export**.
3. Select the song and turn on CapCut's **beat markers** (often a flag icon labelled Beats or Auto beat). Small
   marks appear on every beat. If it misses beats, add markers by hand while the song plays.
4. Put one extra-obvious marker on **the drop**. Everything in the cut sheet counts from it.

## 3. Lay the clips on the beats

1. Follow the cut sheet top to bottom. Drag each clip onto the main track; it snaps to the beat markers.
2. Trim each clip so it ends on the next marker the sheet names. Fast parts: one beat per clip. Calm parts: two to
   four beats per clip.
3. Slow motion: select a clip → **Speed** → about 0.5×. It looks smooth only if the clip was filmed at 60 fps.
4. Clip colour: if clips look blue or grey next to each other, add one **Adjust** layer over everything with a little
   warmth and contrast so the whole reel matches.

## 4. Text

1. **Text** → add a plain text box (skip the templates; they fight the brand).
2. Font: Space Grotesk Bold, all caps. Colour bone `#F2F0ED`; make the last word of a line PR orange `#EA8E3E` (a
   separate text box is easiest).
3. Keep text in the middle of the screen. Nothing in the top 220 px, the bottom 420 px, or the right edge of the
   lower part, where Instagram's buttons sit.
4. Make each text box start exactly on its beat marker. For a "slam", use a quick **In** animation (zoom or pop),
   0.2 s or less.
5. Read every line out loud against the music. If it can't be read in the time it's on screen, cut words.

## 5. The drop (the big moment)

1. **The lift, the bar before the drop:** put one word of the shout on screen per beat ("ONE" · "MORE" · "REP," ·
   "Y'ALL!"), stacked, each with a pop-in. Slow that bar's clip right down so the picture almost freezes.
2. **On the drop:**
   - a single white flash, 2–3 frames long;
   - a short **Camera shake** effect (search the Effects panel for "shake"), about half a second;
   - cut to the most powerful clip.
3. **After the drop:** one cut per beat for the next bar or two. Leave the screen clear of text for the first bar so
   the hit has room.

## 6. The offer

1. Put the logo at the end, with "TRY A FREE WEEK." under it and the website below that.
2. Give it at least 3 seconds.
3. End on a beat, not a fade.

## 7. Export

**Export** at 1080p, 30 fps, MP4. Watch the exported file once on the phone before posting. If the song gets added
in Instagram, line its drop up with the reel's drop there, by ear.

## Checklist before posting

- [ ] The first frame works as the cover: it's the hook line, not a logo.
- [ ] Every member on screen is OK being in an ad.
- [ ] No clip has someone else's text or watermark on it.
- [ ] The music is cleared for a business account (`music.md` → Rights), or it's added inside Instagram.
- [ ] Spelling checked on every line (read them out one by one).
- [ ] No text under Instagram's buttons: preview it in the Instagram upload screen.
- [ ] It makes sense with the sound off, and it's exciting with the sound on.
- [ ] One flash at the drop, no strobing.
